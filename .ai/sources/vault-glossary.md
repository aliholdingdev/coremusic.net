# Kaynak Özeti — glossary.md

## Genel Özet

CoreMusic ekosistemindeki tüm teknik terimlerin tanımlandığı SSOT. v2.0.0 (Faz 1 vault revizyonu) ile genişletilmiş.

## Ana Fikirler

1. 3 adımlı kullanım: §2/§3 tablosunda terim ara → §4/§5 haritasında proje karşılığı/kanıt yolu → derin bağlam için §4.1.x bloğu (ilişkili terim + ADR).
2. Katkısı: yeni terim → §3 tablosu → kanıt araması → kanıt varsa blok, yoksa "DOĞRULAMA GEREKLİ".
3. v2.0.0: mevcut 32 terim birebir korundu + teknoloji yığını terimleri eklendi (Node.js, C++, C#, PHP dünyası, dinamik stack ilkesi — engine §9).
4. Toplam 94 terim (log kaydına göre: 32 kanonik + 11 ekosistem + 51 teknoloji — ⚠ bu sayı kaynak log.md'den, dosyanın içi okunmadı).
