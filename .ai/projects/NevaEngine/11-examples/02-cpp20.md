## §1 Bağlam

Neva Engine'in **ana motoru C++20**'dir (JUCE + ASIO — doc 00/03). Tüm I/O ve DSP yolu
**32-bit float** üzerinden akar (K1-K6 — doc 10 SSOT):

| Kural | İçerik |
|---|---|
| K1 | Input (capture/loopback) **32-bit float** |
| K2 | Internal zincir **32-bit float** (biquad/comp/limiter bu formatta) |
| K3 | Output **32-bit float** — 24-bit int'e düşüşte **TPDF dither zorunlu** |
| K4 | SR **44.1 / 48 / 88.2 / 96 / 176.4 / 192 kHz** · varsayılan **48 kHz** |
| K5 | Cihaz 192 sunmuyorsa → **cihazın en yüksek yerel SR'si** |
| K6 | Bit-perfect = **SR eşit + float32** |

İlgili gereksinimler: **R16** (EQ çift form — parametrik + grafik, aynı biquad motoru) ·
**R10** (compressor + brickwall limiter) · **R18** (cihaz bazlı otomatik varsayılan).

## §2 Örnek 1 — Biquad EQ (R16 çift form) · (R16 · K2)

RBJ peaking koefisyonları + Direct Form I / Transposed DF-II karşılaştırmalı tek bant.
Sınıf/RAII: state ctor'da sıfırlanır, koefisyon `setParams` ile canlı güncellenir (R16).

```cpp
// neva_biquad.hpp — header-only, C++20
#pragma once
#include <algorithm>   // std::clamp
#include <cmath>       // std::sin, std::cos, std::pow
#include <cstddef>

namespace neva {

// RBJ peaking (Audio EQ Cookbook) — normalize edilmiş koefisyonlar (a0 = 1)
struct BiquadCoeffs {
    float b0{}, b1{}, b2{}, a1{}, a2{};
};

[[nodiscard]] inline BiquadCoeffs makePeaking(float f0, float q, float gainDb, float fs) noexcept
{
    // Parametre doğrulama — K4 aralığı içinde (doc 10)
    q       = std::clamp(q, 0.05f, 32.0f);
    f0      = std::clamp(f0, 10.0f, 0.49f * fs);   // Nyquist'e çarpmama
    gainDb  = std::clamp(gainDb, -24.0f, 24.0f);

    constexpr float kPi = 3.14159265358979323846f;
    const float A     = std::pow(10.0f, gainDb / 40.0f);
    const float w0    = 2.0f * kPi * (f0 / fs);
    const float cosw0 = std::cos(w0);
    const float alpha = std::sin(w0) / (2.0f * q);
    const float a0    = 1.0f + alpha / A;

    return BiquadCoeffs{
        (1.0f + alpha * A) / a0,
        (-2.0f * cosw0)    / a0,
        (1.0f - alpha * A) / a0,
        (-2.0f * cosw0)    / a0,
        (1.0f - alpha / A) / a0
    };
}

// Direct Form I — 4 durum değişkeni (referans / yüksek-Q senaryosu)
class BiquadDF1 {
public:
    void setCoeffs(const BiquadCoeffs& c) noexcept { c_ = c; reset(); } // pop'u azalt: sıfırla
    void reset() noexcept { x1_ = x2_ = y1_ = y2_ = 0.0f; }

    [[nodiscard]] float process(float x) noexcept
    {
        const float y = c_.b0 * x + c_.b1 * x1_ + c_.b2 * x2_
                      - c_.a1 * y1_ - c_.a2 * y2_;
        x2_ = x1_; x1_ = x;
        y2_ = y1_; y1_ = y;
        return y;
    }

private:
    BiquadCoeffs c_{};
    float x1_{}, x2_{}, y1_{}, y2_{};
};

// Transposed Direct Form II — 2 durum değişkeni (üretim tercihi: daha az kütülatif hata)
class BiquadDF2T {
public:
    void setCoeffs(const BiquadCoeffs& c) noexcept { c_ = c; reset(); }
    void reset() noexcept { z1_ = z2_ = 0.0f; }

    [[nodiscard]] float process(float x) noexcept
    {
        const float y = c_.b0 * x + z1_;
        z1_ = c_.b1 * x - c_.a1 * y + z2_;
        z2_ = c_.b2 * x - c_.a2 * y;
        return y;
    }

private:
    BiquadCoeffs c_{};
    float z1_{}, z2_{};
};

} // namespace neva
```

**Form karşılaştırması:** DF1 = 4 durum, daha yüksek kütülatif hata · DF2T = 2 durum,
32f'de daha stabil (Neva üretim tercihi). Her iki form da aynı `BiquadCoeffs`'i paylaşır —
R16 çift formun (parametrik ↔ grafik 31 bant) tek motor prensibi.

## §3 Örnek 2 — 32f buffer döngüsü (K2/K4/K5) · (K2 · K4 · K5)

48 kHz varsayılan, interleaved float32 döngüsü, SR fallback enum + switch.

```cpp
// neva_buffer.hpp — header-only, C++20
#pragma once
#include "neva_biquad.hpp"
#include <array>
#include <cstdint>
#include <span>

namespace neva {

inline constexpr std::uint32_t kDefaultRate = 48000;   // K4 varsayılan

// K4 destek listesi — enum class tip güvenli
enum class SampleRate : std::uint32_t {
    R44100  = 44100,
    R48000  = 48000,
    R88200  = 88200,
    R96000  = 96000,
    R176400 = 176400,
    R192000 = 192000
};

[[nodiscard]] inline bool isK4Rate(std::uint32_t sr) noexcept
{
    switch (static_cast<SampleRate>(sr)) {
        case SampleRate::R44100:  case SampleRate::R48000:  case SampleRate::R88200:
        case SampleRate::R96000:  case SampleRate::R176400: case SampleRate::R192000:
            return true;
        default:
            return false;
    }
}

[[nodiscard]] inline const char* rateLabel(std::uint32_t sr) noexcept
{
    switch (static_cast<SampleRate>(sr)) {
        case SampleRate::R44100:  return "44.1 kHz";
        case SampleRate::R48000:  return "48 kHz";
        case SampleRate::R88200:  return "88.2 kHz";
        case SampleRate::R96000:  return "96 kHz";
        case SampleRate::R176400: return "176.4 kHz";
        case SampleRate::R192000: return "192 kHz";
        default:                  return "unsupported";
    }
}

// SR seçimi: tercih → (K6: SR eşit?) → K5 en yüksek yerel SR → K4 48 kHz
[[nodiscard]] inline std::uint32_t pickSampleRate(std::uint32_t preferred,
                                                  std::span<const std::uint32_t> deviceRates)
{
    if (!isK4Rate(preferred)) preferred = kDefaultRate;

    for (const auto r : deviceRates) {                      // K6 adayı: birebir eşit
        if (r == preferred) return preferred;
    }
    std::uint32_t best = 0;                                 // K5 fallback
    for (const auto r : deviceRates) {
        if (isK4Rate(r) && r > best) best = r;
    }
    return best != 0 ? best : kDefaultRate;
}

// Interleaved 32f zincir döngüsü (K1/K2/K3): [L0 R0 L1 R1 ...]
inline void processInterleaved(std::span<float> interleaved,
                               std::uint32_t fs,
                               std::array<BiquadDF2T, 2>& eq /* L/R durumu */) noexcept
{
    const auto frames = interleaved.size() / 2;
    for (std::size_t i = 0; i < frames; ++i) {
        for (std::size_t c = 0; c < 2; ++c) {
            float s = interleaved[i * 2 + c];   // K1: ham 32f — dönüşüm yok
            s = eq[c].process(s);               // K2: DSP float32 üzerinde
            interleaved[i * 2 + c] = s;         // K3: float32 cihaz → bit-perfect (K6)
        }
    }
    (void)fs;   // SR değişiminde koefisyonleri yeniden hesaplamak için çağırır
}

} // namespace neva
```

## §4 Örnek 3 — Lock-free SPSC ring buffer (R10) · (R10)

Atomik head/tail · power-of-2 kapasite · `std::span<float>` depolama · RT güvenli push/pop
(altyapıda malloc yok).

```cpp
// neva_spsc.hpp — header-only, C++20, lock-free SPSC
#pragma once
#include <atomic>
#include <cstddef>
#include <cstdint>
#include <span>

namespace neva {

class SpscRing {
public:
    // Başlatma — NON-RT: storage çağıran tarafın önceden allocate ettiği bellektir.
    // Kapasite MUTLAKA 2^n olmalı; RT yolunda (push/pop) tahsis YOK — R10/zero-allocation.
    [[nodiscard]] static bool create(std::span<float> storage, SpscRing& out) noexcept
    {
        const std::size_t cap = storage.size();
        if (cap == 0 || (cap & (cap - 1)) != 0) return false;   // 2^n değil
        out.data_    = storage;
        out.mask_    = cap - 1;
        out.head_.store(0, std::memory_order_relaxed);
        out.tail_.store(0, std::memory_order_relaxed);
        return true;
    }

    // Yazıcı — RT güvenli: lock yok, block yok, tahsis yok. Doluysa false.
    [[nodiscard]] bool push(float v) noexcept
    {
        const std::size_t head = head_.load(std::memory_order_relaxed);
        const std::size_t next = head + 1;
        const std::size_t tail = tail_.load(std::memory_order_acquire);
        if (next - tail > mask_) return false;               // dolu
        data_[head & mask_] = v;                             // veri yazımı
        head_.store(next, std::memory_order_release);        // release → veri yayınlanır
        return true;
    }

    // Okuyucu — RT güvenli. Boşsa false.
    [[nodiscard]] bool pop(float& out) noexcept
    {
        const std::size_t tail = tail_.load(std::memory_order_relaxed);
        if (tail == head_.load(std::memory_order_acquire)) return false;  // boş
        out = data_[tail & mask_];                           // acquire → veri görünür
        tail_.store(tail + 1, std::memory_order_release);
        return true;
    }

    [[nodiscard]] std::size_t capacityUsable() const noexcept { return mask_ + 1; }

    SpscRing() = default;
    SpscRing(const SpscRing&) = delete;            // tek sahiplik — kopya yok
    SpscRing& operator=(const SpscRing&) = delete;

private:
    std::span<float>          data_{};
    std::size_t               mask_{0};
    // head (yazıcı) / tail (okuyucu) ayrı cache-line'a taşınabilir → false-sharing önlenir:
    // alignas(std::hardware_destructive_interference_size) — libstdc++/libc++ desteği
    // araç-sürücüsüne göre değişir → ⚠️ VERIFICATION REQUIRED (64 sabiti ölçülerek doğrulanır).
    alignas(64) std::atomic<std::size_t> head_{0};
    alignas(64) std::atomic<std::size_t> tail_{0};
};

} // namespace neva
```

## §5 Örnek 4 — WAV 32f okuma/yazma (K3) · (K3 · K1)

44-byte RIFF header · format 3 (IEEE_FLOAT) · 44100–192000 · 32-bit · 2 kanal. Yazma:
header + write; okuma: chunk walk ile minimal parse + doğrulama.

```cpp
// neva_wav.hpp — header-only, C++20 (std ofstream/ifstream — JUCE AudioFormat GEREKMEZ)
#pragma once
#include <array>
#include <cstdint>
#include <cstring>
#include <fstream>
#include <string>
#include <vector>

namespace neva {

inline constexpr std::uint16_t kWavFormatIeeeFloat = 3;   // WAVE_FORMAT_IEEE_FLOAT

struct WavInfo {
    std::uint32_t fs{};
    std::uint16_t channels{};
    std::uint16_t format{};      // 3 olmalı
    std::uint16_t bits{};        // 32 olmalı
    std::uint32_t dataBytes{};
    std::streampos dataPos{};
};

namespace detail {
inline void putU16(std::uint8_t* p, std::uint16_t v) noexcept
{ p[0] = std::uint8_t(v); p[1] = std::uint8_t(v >> 8); }
inline void putU32(std::uint8_t* p, std::uint32_t v) noexcept
{ p[0]=std::uint8_t(v); p[1]=std::uint8_t(v>>8); p[2]=std::uint8_t(v>>16); p[3]=std::uint8_t(v>>24); }
inline std::uint16_t getU16(const std::uint8_t* p) noexcept
{ return std::uint16_t(p[0] | (std::uint16_t(p[1]) << 8)); }
inline std::uint32_t getU32(const std::uint8_t* p) noexcept
{ return std::uint32_t(p[0]) | (std::uint32_t(p[1])<<8) | (std::uint32_t(p[2])<<16) | (std::uint32_t(p[3])<<24); }
} // namespace detail

// Yazma — little-endian host varsayımı (x86/ARM64 LE). K4 sınırı zorlanır.
[[nodiscard]] inline bool writeWavF32(const std::string& path, std::uint32_t fs,
                                      const float* interleaved, std::uint32_t frames,
                                      std::uint16_t channels = 2)
{
    if (fs < 44100 || fs > 192000) return false;                       // K4
    const std::uint32_t dataBytes = frames * channels * 4u;
    std::array<std::uint8_t, 44> h{};
    std::memcpy(&h[0],  "RIFF", 4);  detail::putU32(&h[4],  36u + dataBytes);
    std::memcpy(&h[8],  "WAVE", 4);  std::memcpy(&h[12], "fmt ", 4);
    detail::putU32(&h[16], 16u);                                       // fmt chunk size
    detail::putU16(&h[20], kWavFormatIeeeFloat);                       // format 3 (K1/K3)
    detail::putU16(&h[22], channels);
    detail::putU32(&h[24], fs);
    detail::putU32(&h[28], fs * channels * (32u / 8u));                // byte rate
    detail::putU16(&h[32], std::uint16_t(channels * (32u / 8u)));      // block align
    detail::putU16(&h[34], 32u);                                       // bits/sample
    std::memcpy(&h[36], "data", 4);  detail::putU32(&h[40], dataBytes);

    std::ofstream f(path, std::ios::binary | std::ios::trunc);
    if (!f) return false;
    f.write(reinterpret_cast<const char*>(h.data()), std::streamsize(h.size()));
    f.write(reinterpret_cast<const char*>(interleaved), std::streamsize(dataBytes));
    return static_cast<bool>(f);
    // K3: 24-bit int'e düşüş bu katmanda DEĞİL — yalnız cihaz 24-bit isterse
    // TPDF dither (§6) uygulanır ve round+clamp yapılır (doc 10 K3).
}

// Okuma — chunk walk (RIFF genişletmelerine dayanıklı) + doğrulama
[[nodiscard]] inline bool openWavF32(const std::string& path, WavInfo& info)
{
    std::ifstream f(path, std::ios::binary);
    if (!f) return false;
    std::array<char, 12> hdr{};
    f.read(hdr.data(), 12);
    if (f.gcount() != 12) return false;
    if (std::memcmp(hdr.data(), "RIFF", 4) != 0 || std::memcmp(&hdr[8], "WAVE", 4) != 0)
        return false;

    info = WavInfo{};
    while (true) {
        std::array<char, 8> ch{};
        f.read(ch.data(), 8);
        if (f.gcount() != 8) return false;                       // data bulunamadı
        const std::uint32_t sz = detail::getU32(
            reinterpret_cast<const std::uint8_t*>(&ch[4]));
        if (std::memcmp(ch.data(), "fmt ", 4) == 0) {
            if (sz < 16) return false;
            std::array<std::uint8_t, 16> fmt{};
            f.read(reinterpret_cast<char*>(fmt.data()), 16);
            if (f.gcount() != 16) return false;
            info.format   = detail::getU16(&fmt[0]);
            info.channels = detail::getU16(&fmt[2]);
            info.fs       = detail::getU32(&fmt[4]);
            info.bits     = detail::getU16(&fmt[14]);
            f.seekg(std::streamoff(sz - 16), std::ios::cur);
        } else if (std::memcmp(ch.data(), "data", 4) == 0) {
            info.dataBytes = sz;
            info.dataPos   = f.tellg();
            break;
        } else {
            f.seekg(std::streamoff(sz) + (sz & 1u), std::ios::cur);  // word-alınlı padding
        }
    }

    if (info.format != kWavFormatIeeeFloat) return false;   // format 3 şart (K1)
    if (info.bits   != 32)                 return false;    // 32-bit şart
    if (info.channels == 0 || info.channels > 2) return false;
    if (info.fs < 44100 || info.fs > 192000)     return false;       // K4
    return true;
}

// Tam okuma: doğrulanmış header sonrası data chunk'ı float32 olarak yükler
[[nodiscard]] inline bool readWavF32(const std::string& path,
                                     std::vector<float>& out, WavInfo& info)
{
    if (!openWavF32(path, info)) return false;
    std::ifstream f(path, std::ios::binary);
    if (!f) return false;
    f.seekg(info.dataPos);
    out.resize(info.dataBytes / 4u);          // <4 GiB dosyalar için (stream — Vec sınırı yok denebilir)
    f.read(reinterpret_cast<char*>(out.data()), std::streamsize(info.dataBytes));
    return f.gcount() == static_cast<std::streamsize>(info.dataBytes);
}

} // namespace neva
```

## §6 Örnek 5 — Compressor + brickwall limiter (R10) · (R10 · K3)

Envelope follower (attack 5 ms / release 50 ms, tek kutuplu IIR) → −12 dB / 4:1 → makeup
→ 0 dBFS clamp. K3: 24-bit int düşüşünde TPDF dither.

```cpp
// neva_comp.hpp — header-only, C++20
#pragma once
#include <algorithm>
#include <cmath>
#include <cstdint>

namespace neva {

class Compressor {
public:
    static constexpr float kThresholdDb = -12.0f;
    static constexpr float kRatio       = 4.0f;     // 4:1
    static constexpr float kAttackSec   = 0.005f;   // 5 ms
    static constexpr float kReleaseSec  = 0.050f;   // 50 ms

    void prepare(std::uint32_t fs) noexcept
    {
        env_ = 0.0f;
        atk_ = std::exp(-1.0f / (kAttackSec  * float(fs)));
        rel_ = std::exp(-1.0f / (kReleaseSec * float(fs)));
        thresholdLin_ = std::pow(10.0f, kThresholdDb / 20.0f);
        makeup_ = std::pow(10.0f, (1.0f - 1.0f / kRatio) * (-kThresholdDb) * 0.5f / 20.0f);
        rng_ = 0x12345678u;
    }

    // Tek örnek: compressor + brickwall limiter (K2 — internal 32f)
    [[nodiscard]] float process(float x) noexcept
    {
        const float level = envelope(std::fabs(x));
        float gain = makeup_;
        if (level > thresholdLin_) {
            const float levelDb = 20.0f * std::log10(level + 1.0e-12f);
            const float over    = levelDb - kThresholdDb;
            const float grDb    = -over * (1.0f - 1.0f / kRatio);
            gain *= std::pow(10.0f, grDb / 20.0f);
        }
        float y = x * gain;
        y = std::clamp(y, -1.0f, 1.0f);     // brickwall: 0 dBFS clamp (K3)
        return y;
    }

    // K3: 24-bit int çıkışa düşüşte TPDF dither — iki uniform [-0.5,+0.5] LSB toplamı
    [[nodiscard]] float tpdfDither24() noexcept
    {
        rng_ = rng_ * 1664525u + 1013904223u;                       // LCG (yalnız jitter)
        const float u1 = float(rng_ >> 8) / float(1u << 24);
        rng_ = rng_ * 1664525u + 1013904223u;
        const float u2 = float(rng_ >> 8) / float(1u << 24);
        return (u1 - u2) * (1.0f / 8388608.0f);   // 2^-23 = 1 LSB @24-bit
        // ⚠️ VERIFICATION REQUIRED: üretim RNG seçimi (xoshiro256** vb.) — LCG jitter için yeterli
    }

private:
    [[nodiscard]] float envelope(float inAbs) noexcept
    {
        const float a = (inAbs > env_) ? atk_ : rel_;
        env_ = a * env_ + (1.0f - a) * inAbs;   // tek kutuplu IIR
        return env_;
    }

    float env_{}, atk_{}, rel_{}, thresholdLin_{}, makeup_{};
    std::uint32_t rng_{};
};

} // namespace neva
```

## §7 Örnek 6 — OS/cihaz enum otomatik varsayılan (R18) · (R18 · K4 · K5)

Backend enum (ASIO/WASAPI/ALSA/CoreAudio/NONE) + cihaz-bazlı otomatik varsayılan:
önceki seçim kaydı → yoksa en yüksek SR'lı cihaz → varsayılan 48 kHz.

```cpp
// neva_device.hpp — header-only, C++20 (seçim katmanı — OS API çağrısı YOK)
#pragma once
#include <cstdint>
#include <span>

namespace neva {

enum class Backend : std::uint8_t { None, Asio, Wasapi, Alsa, CoreAudio };

[[nodiscard]] inline const char* backendName(Backend b) noexcept
{
    switch (b) {
        case Backend::Asio:       return "ASIO";
        case Backend::Wasapi:     return "WASAPI";
        case Backend::Alsa:       return "ALSA";
        case Backend::CoreAudio:  return "CoreAudio";
        default:                  return "NONE";
    }
}

[[nodiscard]] inline Backend detectBackend() noexcept
{
#if defined(_WIN32)
    return Backend::Wasapi;      // ASIO varsa init sırasında tercih edilir (os/01)
#elif defined(__APPLE__)
    return Backend::CoreAudio;
#elif defined(__linux__)
    return Backend::Alsa;
#else
    return Backend::None;
#endif
}

struct DeviceCaps {
    Backend       backend{Backend::None};
    std::uint32_t maxRate{};        // cihazın en yüksek yerel SR'si (K5 kaynağı)
    std::uint16_t maxChannels{};
    bool          supportsF32{};    // 32-bit float I/O (K1/K3)
};

struct DeviceProfile {              // R18 — cihaz hafızası (R5 profil sistemiyle entegre)
    bool          hasSaved{};
    Backend       savedBackend{Backend::None};
    std::uint32_t savedRate{};
};

struct Selection {
    Backend       backend{Backend::None};
    std::uint32_t rate{48000};      // K4 varsayılan — yalnız son çare
    bool          fromSaved{};
};

// R18: 1) önceki seçim kaydı → 2) en yüksek SR'lı cihaz (K5) → 3) K4 48 kHz
[[nodiscard]] inline Selection pickDefault(const DeviceProfile& profile,
                                           std::span<const DeviceCaps> caps)
{
    const Backend detected = detectBackend();

    // 1) önceki seçim — cihaz hâlâ destekliyorsa
    if (profile.hasSaved) {
        for (const auto& d : caps) {
            if (d.backend == profile.savedBackend && profile.savedRate <= d.maxRate) {
                return Selection{profile.savedBackend, profile.savedRate, true};
            }
        }
    }

    // 2) en yüksek SR'lı f32 destekli cihaz (K5 — zorlama yok, yerel en yüksek)
    const DeviceCaps* best = nullptr;
    for (const auto& d : caps) {
        if (d.supportsF32 && d.maxRate > 48000 &&
            (best == nullptr || d.maxRate > best->maxRate)) {
            best = &d;
        }
    }
    if (best != nullptr) return Selection{best->backend, best->maxRate, false};

    // 3) varsayılan (K4: 48 kHz) — backend yine tespit edilmiş kalır
    return Selection{detected, 48000, false};
}

} // namespace neva
```

## §8 Dile özel notlar (C++20)

| Başlık | Not |
|---|---|
| **Standart** | **C++20** (`ISO/IEC 14882:2020`) — `std::span`, `std::atomic`, `std::clamp`, `[[nodiscard]]`, `noexcept`, `constexpr`, `enum class`, designated initializer |
| **Bağımlılık** | **Yalnız standart kütüphane**: `<atomic> <algorithm> <cmath> <array> <span> <cstdint> <cstddef> <fstream> <vector> <string> <cstring>` — harici paket YOK (JUCE bu örneklerde yok; üretimde doc 00/03'e bağlanır) |
| **Derleme** | `g++ -std=c++20 -O2 neva_examples.cpp -o neva_examples` (header-only + `main()`: tek TU yeterli) |
| **Sınıf/RAII** | Durum sınıfın içinde ctor/dtor'da yaşar; `SpscRing` kopyalanamaz (`delete`) — tek sahiplik |
| **`noexcept`** | Tüm RT yolu (`process/push/pop`) `noexcept` — exception RT callback'te yasak (Embedded §16: zero-allocation + noexcept) |
| **`[[nodiscard]]`** | Dönüş değeri anlamlı her fonksiyonda (`push/pop/pick/write`) |
| **Pitfall — atomik** | `std::atomic<std::size_t>` lock-free garantisi **standartta zorunlu değil** → `is_always_lock_free` ile derleme zamanı kontrol (x86-64/ARM64 pratikte lock-free). Signal-handler içinde yalnız `is_lock_free()` doğrulanmış atomikler. |
| **Pitfall — `alignas` cacheline** | `std::hardware_destructive_interference_size` libstdc++/libc++'de değişken tanımlı (ODR riski) → örnek 64 sabiti kullandı; **⚠️ VERIFICATION REQUIRED** (hedef toolchain'de ölçüm). |
| **Pitfall — `std::pow/log10`** | `float` overload yoksa `double`'a yükselir → her zaman `10.0f`, `20.0f` gibi `float` literalleri; sıcak yolda lookup table/`exp2f` optimizasyonu Faz 0 benchmark'ı. |
| **Bit-perfect (K6)** | `processInterleaved` ±1.0 aralığında **round-trip kimliktir** (çarpma yoksa); limiter clamp yalnız aşım durumunda devreye girer. |
| **WAV** | Little-endian host varsayımı; big-endian **⚠️ VERIFICATION REQUIRED**. `readWavF32` tam dosyayı `std::vector`'e yükler → pratikte <4 GiB (`data` chunk `uint32`) sınırı vardır. |
