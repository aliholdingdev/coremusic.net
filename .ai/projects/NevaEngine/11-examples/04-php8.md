## §1 Bağlam — PHP'nin Neva'daki rolü

PHP, Neva'da **gerçek zamanlı ses işleme dili DEĞİLDİR**. Rolü (05 §2 control plane +
07 R11):

- **R11 — Yerel PHP sunucusu:** Neva'nın kendi PHP paneli (web mixer UI backend'i) +
  diğer uygulamalara PHP REST/WS API yüzeyi (EQ/FX/preset/çıkış kontrolü).
- **Offline WAV işleme:** dosya bazlı toplu DSP (K6 offline: SR eşit + float32 ise
  bit-perfect sonuç doğrulanabilir).
- **Dürüst sınır:** PHP tek thread'dir (worker'lar hariç), gerçek zamanlı audio callback
  **yoktur** — ASIO/WASAPI hattı C++ çekirdeğindedir (doc 00/03). Bu dosyadaki DSP
  örnekleri **offline/batch** içindir; canlı zincirde kullanılmaz.

**K1-K6 özeti (doc 10 — bağlayıcı):**

| Kural | İçerik |
|---|---|
| K1 | Input **32-bit float** |
| K2 | Internal processing **32-bit float** |
| K3 | Output **32-bit float** (24-bit int düşüşünde **TPDF dither**) |
| K4 | SR **44.1–192 kHz** (varsayılan **48 kHz**) |
| K5 | Cihaz 192 sunmuyorsa → **en yüksek yerel SR** |
| K6 | Bit-perfect = **SR eşit + float32** |

**Dil kuralları (global AGENTS.md):** `declare(strict_types=1)` ilk satır · `final class` ·

hata yönetimi Result yerine tip-güvenli `null`/exception sözleşmesi (offline araç sınıfı).

## §2 Örnek 1 — Biquad EQ (R16 çift form): RBJ peaking + Direct Form I · 48 kHz · K2

> **R16:** aynı biquad motorunun 2 arayüz formu (parametrik + grafik 31 bant) — motor tek,
> arayüz çift. **K2:** iç zincir 32f. RBJ (Audio EQ Cookbook) peaking koef. + Direct Form I.
> Çift form notu: Direct Form I, `x1/x2` ve `y1/y2` durumlu; Direct Form II daha az durumlu
> ama katsayı hassasiyeti daha düşük — yüksek SR (192 kHz) ve dar Q'da DF-I daha güvenlidir.

```php
<?php
declare(strict_types=1);

/**
 * Neva offline EQ — RBJ peaking biquad, Direct Form I.
 * K2 (internal 32f) · K4 (SR 44.1-192k, varsayılan 48k) · R16 (çift form: motor tek).
 * Uyarı: PHP float = float64 (double); float32'e dönüşüm Örnek 2'de (K1/K3 sınırı).
 */
final class BiquadPeaking
{
    // Katsayılar (normalize edilmiş: a0'a bölünmüş) — readonly: hesaplama bir kez yapılır.
    public function __construct(
        private readonly float $b0,
        private readonly float $b1,
        private readonly float $b2,
        private readonly float $a1,
        private readonly float $a2,
    ) {
    }

    /** RBJ peaking: frekans(Hz), Q, kazanç(dB) — 48 kHz varsayılan (K4). */
    public static function peaking(float $freq, float $q, float $gainDb, float $sampleRate = 48000.0): self
    {
        $a = 10.0 ** ($gainDb / 40.0);            // kutup genliği
        $w0 = 2.0 * M_PI * $freq / $sampleRate;   // K4: SR burada geçerli
        $alpha = sin($w0) / (2.0 * $q);
        $cosW0 = cos($w0);

        $b0 = 1.0 + $alpha * $a;
        $b1 = -2.0 * $cosW0;
        $b2 = 1.0 - $alpha * $a;
        $a0 = 1.0 + $alpha / $a;
        $a1 = -2.0 * $cosW0;
        $a2 = 1.0 - $alpha / $a;

        return new self($b0 / $a0, $b1 / $a0, $b2 / $a0, $a1 / $a0, $a2 / $a0);
    }

    /** Dizi üzerinde blok işleme (offline). Kaynak dizi değiştirilmez — yeni dizi döner. */
    public function process(array $samples): array
    {
        $x1 = 0.0; $x2 = 0.0; $y1 = 0.0; $y2 = 0.0;
        $out = [];
        foreach ($samples as $x) {
            // Direct Form I: y = b0x + b1x1 + b2x2 - a1y1 - a2y2
            $y = $this->b0 * $x + $this->b1 * $x1 + $this->b2 * $x2
               - $this->a1 * $y1 - $this->a2 * $y2;
            $x2 = $x1; $x1 = $x;
            $y2 = $y1; $y1 = $y;
            $out[] = $y;
        }
        return $out;
    }
}

// Kullanım (R16): tek motor — parametrik form (f/Q/dB) ve grafik form (31 sabit band)
// aynı sınıfı çağırır; arayüz motoru değiştirmez.
$eq = BiquadPeaking::peaking(freq: 1000.0, q: 1.0, gainDb: 3.5, sampleRate: 48000.0);
```

## §3 Örnek 2 — 32f buffer döngüsü (K2/K4/K5): pack/unpack float32 LE

> **⚠️ DÜRÜST NOT:** PHP'de `float` her zaman **float64'tür (double)** — "PHP float" ifadesi
> 32-bit değildir. K1/K3 float32 sözleşmesi burada bir **değer dönüşümüdür**: `unpack('g')`
> baytları float32 olarak okur ve PHP'ye double'a genişletir (kayıpsız), `pack('g')` double'ı
> float32'e yuvarlayarak yazar (kayıplı — ±1 ULP). Kayıp yalnız 24-bit int'e düşüşte anlamlı;
> K6 bit-perfect iddiası dosya I/O sınırında **float32 yazılan bayt eşitliği** ile ölçülür.
>
> **Format harfleri (PHP pack/unpack):** `'g'` = **little-endian float (32)** ✔ · `'G'` =
> big-endian float (32) · `'e'` = little-endian **double (64)** — K1'de KULLANILMAZ ·
> `'f'` = makineye bağlı float (endianness sabitlenmez) → **portability için `'g'` tercih
> edilir** (WAV IEEE_FLOAT little-endian şartı ile aynı yönde).

```php
<?php
declare(strict_types=1);

/**
 * K2/K4/K5 — 32f buffer döngüsü (offline).
 * K5 fallback: SR listesi (K4) içinden en yüksek geçerli SR seçilir; varsayılan 48k.
 * Dürüst not: PHP real-time değildir — bu döngü toplu/işleme içindir.
 */
final class Float32Buffer
{
    /** K4 destek listesi + K5 fallback (cihaz/en yüksek yerel SR bu listeden seçilir). */
    private const SUPPORTED_SR = [44100, 48000, 88200, 96000, 176400, 192000];
    public const DEFAULT_SR = 48000; // K4 varsayılan

    /** K5: verilen (örn. cihazdan gelen) SR'yi K4 listesine oturt; uymuyorsa en yüksek geçerli. */
    public static function fallbackSampleRate(?int $deviceSr): int
    {
        if ($deviceSr !== null && in_array($deviceSr, self::SUPPORTED_SR, true)) {
            return $deviceSr; // K6: kaynak SR == cihaz SR ise dönüşüm yok
        }
        $best = self::DEFAULT_SR;
        foreach (self::SUPPORTED_SR as $sr) {
            if ($deviceSr === null || $sr <= $deviceSr) {
                $best = max($best, $sr);
            }
        }
        return $best;
    }

    /** float32 LE baytlar → float64 dizi (K1 input okuma — 'g' = LE float32). */
    public static function fromBytes(string $bytes): array
    {
        $unpacked = unpack('g*', $bytes); // 1..n anahtarları, float32 LE → PHP float (double)
        return $unpacked === false ? [] : array_values($unpacked);
    }

    /** float64 dizi → float32 LE baytlar (K3 output yazma — 'g' ile yuvarlanır). */
    public static function toBytes(array $samples): string
    {
        return pack('g*', ...$samples); // double → float32 (değer dönüşümü, yukarıdaki not)
    }

    /** K2 zincir döngüsü: DC offset uygula, K3 clamp [-1.0, 1.0]. */
    public static function processBlock(array $samples, float $dcOffset = 0.0): array
    {
        $out = [];
        foreach ($samples as $s) {
            $y = $s + $dcOffset;
            $out[] = max(-1.0, min(1.0, $y)); // brickwall clamp (K3 — limiter Örnek 5'te)
        }
        return $out;
    }
}
```

## §4 Örnek 3 — Buffer kuyruk/producer-consumer (R10): PHP ring kuyruk

> **⚠️ DÜRÜST NOT:** PHP istek başına tek thread'dir (varsayılan SAPI) — gerçek producer/
> consumer **yoktur**. Bu sınıf offline/batch hattında **mantıksal kuyruk** (WAV segmentleri,
> iş kuyruğu) içindir; kilit **gerekmez** çünkü tek thread. Gerçek lock-free SPSC ring
> (R10/C++ `std::atomic` head/tail) C++ çekirdeğindedir — doc 02/03. Çok-process senaryoda
> PHP'de APCu/DB kuyruğu gerekir (⚠️ VERIFICATION REQUIRED — mimari karar, bu dosyanın
> kapsamı dışı).

```php
<?php
declare(strict_types=1);

/**
 * R10 (offline karşılığı) — sabit boyutlu ring kuyruk (tek thread, kilitsiz).
 * Üretici yazarken tüketicinin ESR'yi bozmaması için döngü tamponu pre-allocate edilir
 * (zero-allocation kuralının PHP karşılığı: döngüde yeni allocate yok).
 */
final class FloatRingQueue
{
    private array $buffer;      // float64 depolama (PHP float = double — Örnek 2 notu)
    private int $head = 0;      // okuma konumu (tüketici)
    private int $tail = 0;      // yazma konumu (üretici)
    private int $count = 0;     // tek thread'de atomiklik gerekmez

    public function __construct(private readonly int $capacity)
    {
        if ($capacity < 1) {
            throw new \InvalidArgumentException('capacity >= 1 olmalı');
        }
        $this->buffer = array_fill(0, $capacity, 0.0); // baştan allocate
    }

    /** Tüketici: dizi bloğunu okur (boşsa null — Result yerine null sözleşmesi). */
    public function dequeue(int $n): ?array
    {
        if ($this->count === 0) {
            return null;
        }
        $n = min($n, $this->count);
        $out = [];
        for ($i = 0; $i < $n; $i++) {
            $out[] = $this->buffer[$this->head];
            $this->head = ($this->head + 1) % $this->capacity;
        }
        $this->count -= $n;
        return $out;
    }

    /** Üretici: doluysa taşma yok — bırakılan sample sayısı döner (backpressure). */
    public function enqueue(array $samples): int
    {
        $written = 0;
        foreach ($samples as $s) {
            if ($this->count === $this->capacity) {
                break; // SPSC'deki "full" durumunun tek-thread karşılığı
            }
            $this->buffer[$this->tail] = $s;
            $this->tail = ($this->tail + 1) % $this->capacity;
            $this->count++;
            $written++;
        }
        return $written;
    }

    public function count(): int { return $this->count; }
    public function isFull(): bool { return $this->count === $this->capacity; }
}
```

## §5 Örnek 4 — WAV 32f okuma/yazma (K3 · K1): RIFF + format 3 (IEEE_FLOAT)

> **K3:** çıktı 32-bit float → WAV `audioFormat = 3` (IEEE_FLOAT). Little-endian zorunlu
> (RIFF/WAVE little-endian) → `v`(u16 LE) / `V`(u32 LE) + `g`(f32 LE) kullanılır.
> `fmt ` chunk 16 bayt yazılır (pratikte yaygın); non-PCM formatlarda 18 bayt (`cbSize=0`)
> yazanlar da vardır — okuyucu chunk zinciri parse etmeli, sihirli ofset kullanmamalı
> (⚠️ VERIFICATION REQUIRED: hedef okuyucu kütüphanesine göre 16/18 bayt test edilecek).

```php
<?php
declare(strict_types=1);

/**
 * K3/K1 — WAV 32f (format 3, IEEE_FLOAT) okuma/yazma (offline).
 * Sınırlama: 4 GB RIFF üst sınırı; 'RIFF' büyük harf sabitleri; data chunk öncesi
 * uzantılı chunk'lar atlanır (LIST/fact vb.) — sihirli 44 bayt ofseti KULLANILMAZ.
 */
final class Wav32f
{
    /** @return array{sampleRate:int, channels:int, samples:array} */
    public static function read(string $path): array
    {
        $fh = fopen($path, 'rb');
        if ($fh === false) {
            throw new \RuntimeException("Açılamadı: {$path}");
        }
        try {
            $header = fread($fh, 12);
            if ($header === false || strlen($header) < 12 || substr($header, 0, 4) !== 'RIFF' || substr($header, 8, 4) !== 'WAVE') {
                throw new \RuntimeException('Geçersiz RIFF/WAVE başlığı');
            }

            $sampleRate = 0; $channels = 0; $bits = 0; $format = 0; $dataSize = 0;
            // Chunk zinciri: id(4) + size(4) — fact/LIST gibi chunk'lar atlanır.
            while (($idSize = fread($fh, 8)) !== false && strlen($idSize) === 8) {
                $id = substr($idSize, 0, 4);
                $size = unpack('V', substr($idSize, 4, 4))[1]; // u32 LE
                if ($id === 'fmt ') {
                    $fmt = fread($fh, $size);
                    $parts = unpack('vformat/vchannels/Vrate/VbyteRate/vblock/vbits', $fmt);
                    $format = $parts['format'];   // 3 = IEEE_FLOAT (K1/K3)
                    $channels = $parts['channels'];
                    $sampleRate = $parts['rate']; // K4/K6: SR buradan okunur
                    $bits = $parts['bits'];
                    if ($size % 2 === 1) { fread($fh, 1); } // chunk pad
                } elseif ($id === 'data') {
                    $dataSize = $size;
                    break;
                } else {
                    fseek($fh, $size + ($size % 2), SEEK_CUR);
                }
            }

            if ($format !== 3 || $bits !== 32) {
                throw new \RuntimeException("Yalnız format 3 (IEEE_FLOAT) / 32 bit desteklenir (gelen: {$format}/{$bits})");
            }
            $bytes = fread($fh, $dataSize);
            if ($bytes === false || strlen($bytes) < $dataSize) {
                throw new \RuntimeException('data chunk okunamadı (truncated)');
            }
            $unpacked = unpack('g*', $bytes); // f32 LE → PHP float (double) — K1 değer dönüşümü
            return [
                'sampleRate' => $sampleRate,
                'channels' => $channels,
                'samples' => array_values($unpacked),
            ];
        } finally {
            fclose($fh);
        }
    }

    /** K3 — 32f WAV yazım. */
    public static function write(string $path, array $samples, int $channels, int $sampleRate): void
    {
        $data = pack('g*', ...$samples);            // f32 LE
        $blockAlign = $channels * 4;                 // 32 bit = 4 bayt
        $byteRate = $sampleRate * $blockAlign;
        $dataSize = strlen($data);

        $fh = fopen($path, 'wb');
        if ($fh === false) {
            throw new \RuntimeException("Yazılamadı: {$path}");
        }
        try {
            // 16 bayt fmt: format(v) channels(v) rate(V) byteRate(V) block(v) bits(v)
            $fmt = pack('vvVVvv', 3, $channels, $sampleRate, $byteRate, $blockAlign, 32);
            // non-PCM'te 18 bayt (cbSize=0) yazanlar da vardır → uyumluluk notu §5'te ⚠️
            $riffSize = 4 + (8 + strlen($fmt)) + (8 + $dataSize);
            fwrite($fh, 'RIFF' . pack('V', $riffSize) . 'WAVE');
            fwrite($fh, 'fmt ' . pack('V', strlen($fmt)) . $fmt);
            fwrite($fh, 'data' . pack('V', $dataSize) . $data);
        } finally {
            fclose($fh);
        }
    }
}
```

## §6 Örnek 5 — Compressor + brickwall limiter (R10): envelope + -12 dB / 4:1 + clamp + TPDF dither (K3)

> **R10:** zincirde compressor → limiter. **K3:** çıkış clamp 0 dBFS; 24-bit int'e düşüşte
> **TPDF dither zorunlu** (K3 kuralı). PHP'de `random_int()` kriptografik PRNG'dir (tohumsuz
> — deterministik replay yok); deterministik dither gerekirse tohumlu PRNG (xorshift32)
`g[++i] = $state` deseni uygulanır (aşağıdaki yorum satırı). Örnek offline çalışır.

```php
<?php
declare(strict_types=1);

/**
 * R10 — peak compressor + brickwall limiter + K3 TPDF dither (offline, K2 32f).
 * Eşik: -12 dBFS · Oran: 4:1 · Attack 5 ms / Release 100 ms (lineer dB domain envelope
 * yerine zarf dedektörü — offline referans amaçlı).
 */
final class CompressorLimiter
{
    private float $envelope = 0.0; // linear zarf durumu

    public function __construct(
        private readonly float $thresholdDb = -12.0,
        private readonly float $ratio = 4.0,
        private readonly float $attackMs = 5.0,
        private readonly float $releaseMs = 100.0,
        private readonly float $sampleRate = 48000.0, // K4 varsayılan
    ) {
    }

    /** @param array $samples K2 32f (PHP float = double) */
    public function process(array $samples): array
    {
        $threshold = 10.0 ** ($this->thresholdDb / 20.0);
        $attackCoef = exp(-1.0 / (($this->attackMs / 1000.0) * $this->sampleRate));
        $releaseCoef = exp(-1.0 / (($this->releaseMs / 1000.0) * $this->sampleRate));
        $out = [];
        foreach ($samples as $x) {
            $absX = abs($x);
            // Peak envelope (attack/release) — R10 dinamik kontrolü
            $this->envelope = $absX > $this->envelope
                ? $attackCoef * $this->envelope + (1.0 - $attackCoef) * $absX
                : $releaseCoef * $this->envelope + (1.0 - $releaseCoef) * $absX;

            $gr = 1.0;
            if ($this->envelope > $threshold && $this->envelope > 0.0) {
                // üstüne çıkan kısım ratio ile: out = thr * (over)^(1/ratio)
                $gr = $threshold * (($this->envelope / $threshold) ** (1.0 / $this->ratio)) / $this->envelope;
            }
            $y = $x * $gr;
            $out[] = max(-1.0, min(1.0, $y)); // brickwall limiter (0 dBFS clamp)
        }
        return $out;
    }

    /**
     * K3 — TPDF dither: iki düzgün rastgele toplamı → [-LSB, +LSB] üçgen PDF.
     * PHP: random_int (tohumsuz). Deterministik replay için: xorshift32 tohumlu PRNG
     * (örn. $s = ($s ^ ($s << 13)) & 0x7fffffff ... — tohum sabitlenmeli).
     * Kullanım: yalnız 24-bit (veya 16-bit) int'e düşüş anında, 1 LSB genlik.
     */
    public static function tpdfDither(float $sample, int $levels = 16777216): float
    {
        $lsb = 1.0 / $levels; // 24-bit: 2^-24
        $r1 = random_int(0, $levels - 1) / ($levels - 1);
        $r2 = random_int(0, $levels - 1) / ($levels - 1);
        return $sample + ($r1 + $r2 - 1.0) * $lsb;
    }
}
```

## §7 Örnek 6 — OS/cihaz enum otomatik varsayılan (R18): PHP_OS_FAMILY + enum

> **R18:** global sabit varsayılan yok — cihaza göre otomatik tespit.
> **⚠️ DÜRÜST SINIR:** PHP'nin **real-time cihaz erişimi YOKTUR** (WASAPI/CoreAudio/ALSA
> sorgusu C++ çekirdeğinde). PHP tarafında yalnız OS ailesi ve sınırlı/bağlamdışı tespit
> (örn. ortam değişkenleri, platform komutu) mümkündür — komut çıktısı biçimleri
> platform/ sürümüne göre değişir → **⚠️ VERIFICATION REQUIRED** (Faz 1 doğrulaması).
> Gerçek SR/cihaz enum'u R18'i C++ çekirdek uygular; PHP yalnız sonucu JSON olarak okur.

```php
<?php
declare(strict_types=1);

/**
 * R18 — OS enum (PHP 8.1+ backed enum) + yerel cihaz tespiti SINIRI.
 * Dürüst not: PHP cihaz SR'sini doğrudan sorgulayamaz; K5 fallback Örnek 2'deki
 * fallbackSampleRate() üzerinden yalnız verilen değerle uygulanır.
 */
enum OsFamily: string
{
    case Windows = 'windows';
    case Darwin  = 'darwin';  // macOS
    case Linux   = 'linux';
    case Bsd     = 'bsd';
    case Other   = 'other';

    public static function current(): self
    {
        // PHP_OS_FAMILY: 'Windows' | 'Darwin' | 'Linux' | 'BSD' | 'Other' (PHP 7.2+)
        return match (PHP_OS_FAMILY) {
            'Windows' => self::Windows,
            'Darwin'  => self::Darwin,
            'Linux'   => self::Linux,
            'BSD'     => self::Bsd,
            default   => self::Other,
        };
    }
}

/**
 * Cihaz yeteneği verisi PHP'de ÜRETİLMEZ — çekirdekten JSON ile gelir (R18 → control plane).
 * Bu DTO yalnız sözleşmeyi tipleştirir (readonly + enum).
 */
final readonly class DeviceCapability
{
    public function __construct(
        public OsFamily $os,
        public int $sampleRate,   // K5: cihazın en yüksek yerel SR'si (çekirdekten)
        public int $bufferFrames, // ör. 512
        public int $channels,
    ) {
    }

    /** K5/K4: cihaz SR'sini K4 listesine oturt (Örnek 2 fallback) — varsayılan 48k. */
    public function effectiveSampleRate(): int
    {
        return Float32Buffer::fallbackSampleRate($this->sampleRate);
    }

    /** K6: bit-perfect kapısı — kaynak SR == cihaz SR ise dönüşüm yok. */
    public function isBitPerfect(int $sourceSampleRate): bool
    {
        return $sourceSampleRate === $this->effectiveSampleRate();
    }
}
```

## §8 Dile özel notlar

1. **PHP float = float64 (double):** her yerde geçerli. float32 I/O yalnız
   `pack('g')`/`unpack('g')` ile yapılır; `'f'` makineye bağlıdır, `'g'` LE garantilidir
   (WAV IEEE_FLOAT LE ile aynı). `'e'`/`'E'` 64-bit double içindir — K1'de kullanılmaz.
2. **Real-time yok:** `declare(strict_types=1)` + `final class` + `readonly` + `enum`
   (8.1) — ama ses işi **offline/batch**. Canlı zincir C++ çekirdek (doc 00/03).
3. **Tek thread:** Örnek 3 ring kuyrukta kilit gereksiz; çok-process senaryo
   APCu/DB kuyruğu → mimari karar (⚠️ VERIFICATION REQUIRED).
4. **Deterministiklik:** `random_int()` tohumsuz → K3 TPDF dither'da replay üretilemez;
   deterministik gerekiyorsa tohumlu PRNG (xorshift32/mulberry32) gerekir.
5. **Bağımlılık:** bu dosyalarda PDO/curl/ext ekleme YOKTUR — standart kütüphane
   (`pack/unpack/fopen/exp/sin/cos`) yeterlidir; bağımlılık kontrolü gereksiz.

   (`fmt `/`data` + pad) döngüsü ile ilerler (uyumluluk: 16/18 bayt fmt — §5 notu ⚠️).
