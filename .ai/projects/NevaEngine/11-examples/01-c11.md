# Neva Engine — C11 Kod Örnekleri

## §1 Bağlam

Neva Engine, platformlar arası bir ses motorudur; tüm I/O ve DSP yolu **32-bit float**
üzerinden akar (K1-K6 — doc 10 SSOT):

| Kural | İçerik |
|---|---|
| K1 | Input (capture/loopback) **32-bit float** |
| K2 | Internal zincir **32-bit float** (biquad/comp/limiter bu formatta) |
| K3 | Output **32-bit float** — 24-bit int'e düşüşte **TPDF dither zorunlu** |
| K4 | SR **44.1 / 48 / 88.2 / 96 / 176.4 / 192 kHz** · varsayılan **48 kHz** |
| K5 | Cihaz 192 sunmuyorsa → **cihazın en yüksek yerel SR'si** (zorlama yok) |
| K6 | Bit-perfect = **SR eşit + float32** (aksi halde tek noktada SRC/dither) |

İlgili gereksinimler: **R16** (EQ çift form — parametrik + grafik, aynı biquad motoru) ·
**R10** (compressor + brickwall limiter zincirde) · **R18** (global sabit varsayılan yok —
cihaz bazlı otomatik tespit).

## §2 Örnek 1 — Biquad EQ (R16 çift form) · (R16 · K2)

RBJ (Audio EQ Cookbook) peaking koefisyonları + **Direct Form I** ve **Transposed Direct
Form II** karşılaştırmalı tek bant. `process()` örnek fonksiyonu DF1 üzerindedir; iki form
aynı koefisyonları paylaşır (R16: parametrik/grafik iki arayüz = aynı motor).

```c
/* neva_biquad.c — C11, tek dosya: gcc -std=c11 -O2 neva_biquad.c -lm */
#include <math.h>
#include <stddef.h>

#define NEVA_PI_F 3.14159265358979323846f

/* Direct Form I durumu (6 durum değişkeni — kare gürültüye daha dayanıklı) */
typedef struct {
    float b0, b1, b2;   /* normalize edilmiş (a0'e bölünmüş) koefisyonlar */
    float a1, a2;       /* a0 = 1 varsayımı */
    float x1, x2;       /* gecikmeli girdi   x[n-1], x[n-2] */
    float y1, y2;       /* gecikmeli çıkış   y[n-1], y[n-2] */
} neva_biquad_df1_t;

/* Transposed Direct Form II durumu (2 durum değişkeni — kümülatif hatası daha az) */
typedef struct {
    float b0, b1, b2;
    float a1, a2;
    float z1, z2;       /* durum değişkenleri */
} neva_biquad_df2t_t;

/* RBJ peaking: f0 (Hz), Q, gain_dB — fs = örnekleme hızı (K4: 44100..192000) */
static inline void neva_biquad_peaking(float *b0, float *b1, float *b2,
                                       float *a1, float *a2,
                                       float f0, float q, float gain_db, float fs)
{
    /* Parametre doğrulama (MISRA-dostu kısa fonksiyon) */
    if (q < 0.05f) { q = 0.05f; }                    /* Q alt sınırı */
    if (f0 < 10.0f) { f0 = 10.0f; }                  /* alt kenar */
    if (f0 > 0.49f * fs) { f0 = 0.49f * fs; }        /* Nyquist'e çarpmama */

    const float A     = powf(10.0f, gain_db / 40.0f);   /* amplitude = sqrt(linear) */
    const float w0    = 2.0f * NEVA_PI_F * (f0 / fs);
    const float cosw0 = cosf(w0);
    const float alpha = sinf(w0) / (2.0f * q);
    const float a0    = 1.0f + alpha / A;

    *b0 = (1.0f + alpha * A) / a0;
    *b1 = (-2.0f * cosw0)    / a0;
    *b2 = (1.0f - alpha * A) / a0;
    *a1 = (-2.0f * cosw0)    / a0;
    *a2 = (1.0f - alpha / A) / a0;
}

/* Bantı hazırla (tüm K2 processing float32 — bkz. doc 10) */
static inline void neva_df1_init(neva_biquad_df1_t *s,
                                 float f0, float q, float gain_db, float fs)
{
    neva_biquad_peaking(&s->b0, &s->b1, &s->b2, &s->a1, &s->a2, f0, q, gain_db, fs);
    s->x1 = s->x2 = s->y1 = s->y2 = 0.0f;   /* sıfır durum (DC offset yok) */
}

/* Örnek başına tek bant işlemi — Direct Form I */
static inline float neva_df1_process(neva_biquad_df1_t *s, float x)
{
    const float y = s->b0 * x
                  + s->b1 * s->x1 + s->b2 * s->x2
                  - s->a1 * s->y1 - s->a2 * s->y2;
    s->x2 = s->x1;  s->x1 = x;
    s->y2 = s->y1;  s->y1 = y;
    return y;
}

/* Aynı koefisyonlarla transposed DF-II — karşılaştırma/benchmark için */
static inline float neva_df2t_process(neva_biquad_df2t_t *s, float x)
{
    const float y = s->b0 * x + s->z1;
    s->z1 = s->b1 * x - s->a1 * y + s->z2;
    s->z2 = s->b2 * x - s->a2 * y;
    return y;
}
```

**Form karşılaştırması (tek bant, 48 kHz):**

| Kriter | Direct Form I | Transposed DF-II |
|---|---|---|
| Durum değişkeni | 4 (x1,x2,y1,y2) | 2 (z1,z2) |
| 32f kayan noktada kütülatif hata | daha yüksek (özellikle yüksek Q) | daha düşük (önerilen) |
| Parametre değişimi (canlı EQ sürükleme — R16) | durumu **sıfırlamak gerekir** (pop sesi riski) | aynı — sıfırlama gerekir, pop daha az |
| Öneri (Neva) | referans/okuma | **üretim tercihi** (2 durum, hızlı) |

Not (R16 çift form): parametrik ve grafik (31 bant) arayüzleri **aynı** koefisyon fonksiyonunu
çağırır; yalnızca f0/Q/gain kaynağı değişir (slider vs. preset).

## §3 Örnek 2 — 32f buffer döngüsü (K2/K4/K5) · (K2 · K4 · K5)

48 kHz varsayılan, interleaved float32 döngüsü, SR fallback enum/switch ile.

```c
/* neva_buffer.c — K4 whitelist SR + K5 fallback + interleaved 32f döngü (K2) */
#include <stdint.h>
#include <stddef.h>

#define NEVA_DEFAULT_RATE 48000u   /* K4 varsayılan (CLAUDE §19 standart) */

/* K4 destek listesi — enum değerleri doğrudan Hz */
typedef enum {
    NEVA_SR_NONE    = 0,
    NEVA_SR_44100   = 44100,
    NEVA_SR_48000   = 48000,
    NEVA_SR_88200   = 88200,
    NEVA_SR_96000   = 96000,
    NEVA_SR_176400  = 176400,
    NEVA_SR_192000  = 192000
} neva_sr_t;

static int neva_sr_is_k4(uint32_t sr)
{
    switch ((neva_sr_t)sr) {
        case NEVA_SR_44100:  case NEVA_SR_48000:  case NEVA_SR_88200:
        case NEVA_SR_96000:  case NEVA_SR_176400: case NEVA_SR_192000:
            return 1;
        default:
            return 0;   /* K4 dışı — reddet */
    }
}

static const char *neva_sr_label(uint32_t sr)
{
    switch ((neva_sr_t)sr) {
        case NEVA_SR_44100:  return "44.1 kHz";
        case NEVA_SR_48000:  return "48 kHz";
        case NEVA_SR_88200:  return "88.2 kHz";
        case NEVA_SR_96000:  return "96 kHz";
        case NEVA_SR_176400: return "176.4 kHz";
        case NEVA_SR_192000: return "192 kHz";
        default:             return "unsupported";
    }
}

/*
 * SR seçimi: tercih edilen SR cihazda var mı? (K6 bit-perfect kapısı = SR eşit)
 * Yoksa → K5: cihazın en yüksek YEREL SR'si (K4 listesi içinden).
 * Hiçbiri yoksa → K4 varsayılan 48 kHz.
 */
static uint32_t neva_pick_sample_rate(uint32_t preferred,
                                      const uint32_t *device_rates, size_t count)
{
    size_t i;
    uint32_t best = 0u;

    if (!neva_sr_is_k4(preferred)) {
        preferred = NEVA_DEFAULT_RATE;               /* K4 dışındaki tercih reddedilir */
    }
    for (i = 0u; i < count; i++) {
        if (device_rates[i] == preferred) {
            return preferred;                        /* K6: SR eşit → bit-perfect adayı */
        }
    }
    /* K5 fallback: en yüksek yerel SR (192 değil — cihaz sunmuyorsa zorlama yok) */
    for (i = 0u; i < count; i++) {
        if (neva_sr_is_k4(device_rates[i]) && device_rates[i] > best) {
            best = device_rates[i];
        }
    }
    return (best != 0u) ? best : NEVA_DEFAULT_RATE;
}

/* Interleaved 32f zincir döngüsü (K2): [L0 R0 L1 R1 ...] — 2 kanal */
#include "neva_biquad.c"   /* §2'deki biquad (tek dosya birleştirmesi) */

void neva_process_interleaved(float *interleaved, size_t frames, unsigned channels,
                              uint32_t fs,
                              neva_biquad_df1_t *eq /* channels başına durum */)
{
    size_t n = frames * (size_t)channels;
    size_t i;

    for (i = 0u; i < n; i += (size_t)channels) {
        unsigned c;
        for (c = 0u; c < channels; c++) {
            float s = interleaved[i + c];          /* K1/K2: ham 32f — upcast yok */
            s = neva_df1_process(&eq[c], s);       /* K2: DSP float32 üzerinde */
            interleaved[i + c] = s;                /* K3: cihaz float32 sunarsa bit-perfect */
        }
    }
    (void)fs;   /* parametre, örn. canlı SR değişiminde koefisyon yeniden hesabına gider */
}
```

## §4 Örnek 3 — Lock-free SPSC ring buffer (R10) · (R10)

Tek yazıcı / tek okuyucu (SPSC) kuyruk: atomik head/tail, power-of-2 kapasite, real-time
güvenli push/pop — **RT yolunda malloc/free/yok** (zero-allocation kuralı). C11:
`<stdatomic.h>` · `memory_order_acquire/release`.

```c
/* neva_spsc.c — lock-free SPSC, kapasite 2^n, altyapıda tek seferlik allocate */
#include <stdatomic.h>
#include <stdint.h>
#include <stdbool.h>
#include <stddef.h>

typedef struct {
    float          *buf;      /* başlatma ÖNCESİ allocate edilir (RT yolunda malloc YOK) */
    size_t          mask;     /* kapasite - 1 (kapasite mutlaka 2^n olmalı) */
    _Atomic size_t  head;     /* yazıcı yazma indeksi (monoton artar, taşar) */
    _Atomic size_t  tail;     /* okuyucu okuma indeksi (monoton artar, taşar) */
} neva_spsc_t;

/* Başlatma — NON-RT context (engine init). Kapasite 2^n doğrulanır. */
static inline bool neva_spsc_init(neva_spsc_t *q, float *storage, size_t capacity_pow2)
{
    if (q == NULL || storage == NULL) { return false; }
    if (capacity_pow2 == 0u || (capacity_pow2 & (capacity_pow2 - 1u)) != 0u) {
        return false;   /* power-of-2 değil */
    }
    q->buf  = storage;
    q->mask = capacity_pow2 - 1u;
    atomic_init(&q->head, 0u);
    atomic_init(&q->tail, 0u);
    return true;
}

/* Yazıcı — RT güvenli: kopya + atomik store, lock yok, block yok. Doluysa false. */
static inline bool neva_spsc_push(neva_spsc_t *q, float v)
{
    const size_t head  = atomic_load_explicit(&q->head, memory_order_relaxed);
    const size_t next  = head + 1u;
    const size_t tail  = atomic_load_explicit(&q->tail, memory_order_acquire);

    if ((next - tail) > q->mask) {
        return false;                     /* dolu — drop/overflow politikası çağıranın */
    }
    q->buf[head & q->mask] = v;           /* veri yazımı */
    atomic_store_explicit(&q->head, next, memory_order_release);
    return true;                          /* release: veri yazımı head yayınlanmadan görünmez */
}

/* Okuyucu — RT güvenli. Boşsa false. */
static inline bool neva_spsc_pop(neva_spsc_t *q, float *out)
{
    const size_t tail = atomic_load_explicit(&q->tail, memory_order_relaxed);
    const size_t head = atomic_load_explicit(&q->head, memory_order_acquire);

    if (tail == head) {
        return false;                     /* boş */
    }
    *out = q->buf[tail & q->mask];        /* acquire: head'den önce okunan veri bayt bayt görünür */
    atomic_store_explicit(&q->tail, tail + 1u, memory_order_release);
    return true;
}
```

Neden lock-free (R10 — compressor/limiter zinciri dahil tüm RT hattı için):
- Yalnız 1 yazıcı + 1 okuyucu → klasik ABA/reorder senaryosu yok; head/tail ayrı cacheline'a
  taşınabilir (`alignas(64)` — C11 `<stdalign.h>` — tipik false-sharing önlemi, araç bağımlı).
- `malloc` yalnız init'te; callback yolunda tahsis yok (zero-allocation).

## §5 Örnek 4 — WAV 32f okuma/yazma (K3) · (K3 · K1)

44-byte RIFF header · format code **3 (WAVE_FORMAT_IEEE_FLOAT)** · SR 44100–192000 ·
32-bit · 2 kanal. Yazma: header struct + write. Okuma: minimal parse + chunk walk doğrulama.

```c
/* neva_wav.c — IEEE float32 WAV, little-endian host varsayımı (x86/ARM64 LE) */
#include <stdio.h>
#include <stdint.h>
#include <string.h>

#define NEVA_WAV_FMT_IEEE_FLOAT 3u   /* WAVE_FORMAT_IEEE_FLOAT */
#define NEVA_WAV_BITS           32u
#define NEVA_WAV_CH             2u

/* Little-endian alan yazım yardımcıları (struct padding'e güvenmeyiz — portability) */
static void put_u16_le(uint8_t *p, uint16_t v) { p[0]=(uint8_t)v; p[1]=(uint8_t)(v>>8); }
static void put_u32_le(uint8_t *p, uint32_t v)
{
    p[0]=(uint8_t)v; p[1]=(uint8_t)(v>>8); p[2]=(uint8_t)(v>>16); p[3]=(uint8_t)(v>>24);
}
static uint16_t get_u16_le(const uint8_t *p) { return (uint16_t)(p[0] | ((uint16_t)p[1]<<8)); }
static uint32_t get_u32_le(const uint8_t *p)
{
    return (uint32_t)p[0] | ((uint32_t)p[1]<<8) | ((uint32_t)p[2]<<16) | ((uint32_t)p[3]<<24);
}

/* 44-byte standart header: RIFF(12) + fmt (24) + data(8) */
static void neva_wav_header(uint8_t h[44], uint32_t fs, uint32_t data_bytes)
{
    memcpy(&h[0],  "RIFF", 4);
    put_u32_le(&h[4],  36u + data_bytes);          /* RIFF chunk size */
    memcpy(&h[8],  "WAVE", 4);
    memcpy(&h[12], "fmt ", 4);
    put_u32_le(&h[16], 16u);                        /* fmt chunk size (PCM-tüp) */
    put_u16_le(&h[20], (uint16_t)NEVA_WAV_FMT_IEEE_FLOAT);  /* format 3 */
    put_u16_le(&h[22], (uint16_t)NEVA_WAV_CH);      /* 2 kanal */
    put_u32_le(&h[24], fs);                         /* 44100..192000 (K4) */
    put_u32_le(&h[28], fs * NEVA_WAV_CH * (NEVA_WAV_BITS/8u)); /* byte rate */
    put_u16_le(&h[32], (uint16_t)(NEVA_WAV_CH * (NEVA_WAV_BITS/8u))); /* block align */
    put_u16_le(&h[34], (uint16_t)NEVA_WAV_BITS);    /* 32 bit/sample */
    memcpy(&h[36], "data", 4);
    put_u32_le(&h[40], data_bytes);
}

/* Yazma: 32f doğrudan yazılır (K3) — 24-bit int'e düşüş TPDF dither'i bu katmanda DEĞİL,
   yalnız cihaz 24-bit isterse uygulanır (bkz. §6 limiter örneği + doc 10 K3). */
int neva_wav_write_f32(const char *path, uint32_t fs,
                       const float *interleaved, uint32_t frames)
{
    uint8_t h[44];
    FILE *f;
    uint32_t data_bytes = frames * NEVA_WAV_CH * 4u;

    if (fs < 44100u || fs > 192000u) { return -1; }          /* K4 sınırı */
    f = fopen(path, "wb");
    if (f == NULL) { return -2; }

    neva_wav_header(h, fs, data_bytes);
    if (fwrite(h, 1u, 44u, f) != 44u) { fclose(f); return -3; }
    if (fwrite(interleaved, 4u, (size_t)frames * NEVA_WAV_CH, f)
        != (size_t)frames * NEVA_WAV_CH) { fclose(f); return -3; }
    if (fclose(f) != 0) { return -3; }
    return 0;
}

/* Okuma — minimal chunk walk + doğrulama (RIFF genişletmelerine dayanıklı) */
typedef struct {
    uint32_t fs;
    uint16_t channels;
    uint16_t format;      /* 3 olmalı */
    uint16_t bits;        /* 32 olmalı */
    uint32_t data_bytes;
    long     data_offset; /* data chunk'un dosyadaki başlangıcı */
} neva_wav_info_t;

int neva_wav_open_f32(const char *path, neva_wav_info_t *info)
{
    uint8_t hdr[12], ch[8];
    FILE *f = fopen(path, "rb");
    if (f == NULL) { return -1; }

    if (fread(hdr, 1u, 12u, f) != 12u) { fclose(f); return -2; }
    if (memcmp(hdr, "RIFF", 4) != 0 || memcmp(&hdr[8], "WAVE", 4) != 0) {
        fclose(f); return -3;                     /* RIFF/WAVE değil */
    }

    memset(info, 0, sizeof(*info));
    while (fread(ch, 1u, 8u, f) == 8u) {          /* chunk walk */
        uint32_t sz = get_u32_le(&ch[4]);
        if (memcmp(ch, "fmt ", 4) == 0) {
            uint8_t fmt[16];
            if (sz < 16u || fread(fmt, 1u, 16u, f) != 16u) { fclose(f); return -4; }
            info->format   = get_u16_le(&fmt[0]);
            info->channels = get_u16_le(&fmt[2]);
            info->fs       = get_u32_le(&fmt[4]);
            info->bits     = get_u16_le(&fmt[14]);
            if (fseek(f, (long)sz - 16l, SEEK_CUR) != 0) { fclose(f); return -4; }
        } else if (memcmp(ch, "data", 4) == 0) {
            info->data_bytes  = sz;
            info->data_offset = ftell(f);
            break;                                /* data bulundu — çık */
        } else {
            if (fseek(f, (long)sz + (long)(sz & 1u), SEEK_CUR) != 0) { fclose(f); return -4; }
            /* ^ bilinmeyen chunk atla; WAVE chunk'ları word-hizalı (odd size +1 padding) */
        }
    }
    fclose(f);

    if (info->data_offset == 0l)           { return -5; }  /* data chunk yok */
    if (info->format != NEVA_WAV_FMT_IEEE_FLOAT) { return -6; }  /* format 3 şart (K1) */
    if (info->bits   != NEVA_WAV_BITS)     { return -7; }  /* 32-bit şart */
    if (info->channels == 0u || info->channels > 2u) { return -8; }
    if (info->fs < 44100u || info->fs > 192000u)    { return -9; }  /* K4 */
    return 0;
}
```

## §6 Örnek 5 — Compressor + brickwall limiter (R10) · (R10 · K3)

Envelope follower (attack 5 ms / release 50 ms, tek kutuplu IIR) → threshold −12 dB ·
ratio 4:1 → makeup → limiter clamp 0 dBFS. K3 notu: 24-bit int çıkışa düşüşte **TPDF dither**.

```c
/* neva_comp.c — tek bant compressor + brickwall limiter (R10 zincir sırası: FX → comp → lim) */
#include <math.h>

typedef struct {
    /* tek kutuplu envelope (çizgi/common-mode seviye takibi) */
    float env;          /* linearMagnitude envelope */
    float atk_coef;     /* exp(-1 / (attack_s  * fs)) */
    float rel_coef;     /* exp(-1 / (release_s * fs)) */
    /* dinamik */
    float threshold_lin;  /* -12 dBFS */
    float ratio;          /* 4.0 */
    float makeup_lin;     /* otomatik makeup (aşağıda hesaplanır) */
    uint32_t rng;         /* TPDF dither için LCG durumu (K3) */
} neva_comp_t;

#define NEVA_COMP_THRESH_DB (-12.0f)
#define NEVA_COMP_RATIO     4.0f
#define NEVA_COMP_ATK_S     0.005f    /* 5 ms  */
#define NEVA_COMP_REL_S     0.050f    /* 50 ms */

static inline void neva_comp_init(neva_comp_t *c, uint32_t fs)
{
    c->env = 0.0f;
    c->atk_coef = expf(-1.0f / (NEVA_COMP_ATK_S * (float)fs));
    c->rel_coef = expf(-1.0f / (NEVA_COMP_REL_S * (float)fs));
    c->threshold_lin = powf(10.0f, NEVA_COMP_THRESH_DB / 20.0f);
    c->ratio = NEVA_COMP_RATIO;
    /* Makeup: threshold üstünde beklenen GR kadar kazanç (kaba eşitlik — tuning gerekir) */
    c->makeup_lin = powf(10.0f, (1.0f - 1.0f / NEVA_COMP_RATIO)
                              * (-NEVA_COMP_THRESH_DB) * 0.5f / 20.0f);
    c->rng = 0x12345678u;
}

/* Tek kutuplu IIR envelope: attack'e göre yüksel, release'e göre düş */
static inline float neva_env_follow(neva_comp_t *c, float in_abs)
{
    if (in_abs > c->env) {
        c->env = c->atk_coef * c->env + (1.0f - c->atk_coef) * in_abs;
    } else {
        c->env = c->rel_coef * c->env + (1.0f - c->rel_coef) * in_abs;
    }
    return c->env;
}

/* Compressor + limiter — tek örnek (K2: internal 32f) */
static inline float neva_comp_process(neva_comp_t *c, float x)
{
    const float level = neva_env_follow(c, fabsf(x));
    float gain = 1.0f;

    if (level > c->threshold_lin) {
        /* dB domeni: over → ratio eğrisi (4:1) */
        const float level_db = 20.0f * log10f(level + 1.0e-12f);
        const float over     = level_db - NEVA_COMP_THRESH_DB;
        const float gr_db     = -over * (1.0f - 1.0f / c->ratio);
        gain = powf(10.0f, (gr_db) / 20.0f) * c->makeup_lin;
    } else {
        gain = c->makeup_lin;
    }

    float y = x * gain;

    /* Brickwall limiter: 0 dBFS clamp (K3 — çıkış asla ±1.0'i aşmaz) */
    if (y > 1.0f)      { y = 1.0f; }
    else if (y < -1.0f){ y = -1.0f; }
    return y;
}

/* K3: 24-bit int'e düşüşte TPDF dither — iki bağımsız uniform [-0.5,+0.5] LSB toplamı.
   KALİBRE LSB: 24-bit'te 2^-23 (tam ölçek ±1.0 float). */
static inline float neva_tpdf_dither24(neva_comp_t *c)
{
    /* LCG (yalnız dither jitter'i için yeterli — kripto DEĞİL).
       ⚠️ VERIFICATION REQUIRED: üretimde daha iyi RNG (ör. xoshiro) değerlendirilecek. */
    float u1, u2;
    c->rng = c->rng * 1664525u + 1013904223u;
    u1 = (float)(c->rng >> 8) / (float)(1u << 24);
    c->rng = c->rng * 1664525u + 1013904223u;
    u2 = (float)(c->rng >> 8) / (float)(1u << 24);
    return (u1 - u2) * (1.0f / 8388608.0f);   /* 2^-23 = 1 LSB @24-bit */
}
```

K3 zincir notu: cihaz **float32** sunuyorsa (K6 koşulu) dither **uygulanmaz**; yalnız
24-bit int çıkışa dönüşüm noktasında `neva_tpdf_dither24()` çağrılır ve ardından
`round-to-nearest` + clamp yapılır (doc 10 §1 K3 — dither zorunlu).

## §7 Örnek 6 — OS/cihaz enum otomatik varsayılan (R18) · (R18 · K4 · K5)

Backend enum (ASIO/WASAPI/ALSA/CoreAudio/NONE) + cihaz-bazlı otomatik varsayılan seçim:
önceki seçim kaydı → yoksa en yüksek SR'lı cihaz → varsayılan 48 kHz.

```c
/* neva_device.c — R18: global sabit varsayılan YOK; her şey cihazdan türetilir */
#include <stdint.h>
#include <stddef.h>

typedef enum {
    NEVA_BACKEND_NONE = 0,
    NEVA_BACKEND_ASIO,        /* Windows — düşük gecikme (R3 <10 ms hedefi) */
    NEVA_BACKEND_WASAPI,      /* Windows — exclusive/shared + loopback (K1) */
    NEVA_BACKEND_ALSA,        /* Linux   — SND_PCM_FORMAT_FLOAT_LE (K1) */
    NEVA_BACKEND_COREAUDIO    /* macOS   — AUHAL float32 (K1) */
} neva_backend_t;

typedef struct {
    neva_backend_t backend;
    uint32_t       max_rate;      /* cihazın en yüksek yerel SR'si (K5 kaynağı) */
    uint16_t       max_channels;
    int            supports_f32;  /* 1 = 32-bit float I/O (K1/K3) */
} neva_device_caps_t;

typedef struct {
    int            has_saved;     /* önceki seçim kaydı var mı? */
    neva_backend_t saved_backend;
    uint32_t       saved_rate;
} neva_device_profile_t;          /* R5 profil sistemiyle entegre (doc 06 R18) */

static const char *neva_backend_name(neva_backend_t b)
{
    switch (b) {
        case NEVA_BACKEND_ASIO:      return "ASIO";
        case NEVA_BACKEND_WASAPI:    return "WASAPI";
        case NEVA_BACKEND_ALSA:      return "ALSA";
        case NEVA_BACKEND_COREAUDIO: return "CoreAudio";
        default:                     return "NONE";
    }
}

/* Backend seçimi: OS'e göre mevcut en iyi backend (NONE = hiçbir API yok) */
static neva_backend_t neva_detect_backend(void)
{
#if defined(_WIN32)
    return NEVA_BACKEND_WASAPI;   /* ASIO varsa init sırasında tercih edilir (os/01) */
#elif defined(__APPLE__)
    return NEVA_BACKEND_COREAUDIO;
#elif defined(__linux__)
    return NEVA_BACKEND_ALSA;
#else
    return NEVA_BACKEND_NONE;
#endif
}

/*
 * Otomatik varsayılan (R18):
 *   1) önceki seçim kaydı varsa ve cihaz hâlâ destekliyorsa → onu kullan
 *   2) yoksa → cihaz profillerinden en yüksek SR'lı cihaz (K5: 192 değil, yerel en yüksek)
 *   3) o da yoksa → K4 varsayılan 48 kHz
 */
typedef struct {
    neva_backend_t backend;
    uint32_t       rate;
    int            from_saved;    /* teşhis/telemetri için köken işareti */
} neva_selection_t;

static neva_selection_t neva_pick_default(const neva_device_profile_t *profile,
                                          const neva_device_caps_t *caps_list,
                                          size_t count)
{
    neva_selection_t sel;
    size_t i;
    size_t best_i = (size_t)-1;
    uint32_t best_rate = 0u;

    sel.backend = neva_detect_backend();
    sel.rate = 48000u;          /* K4 varsayılan — yalnız son çare */
    sel.from_saved = 0;

    /* 1) Önce seçim kaydı (R18 — cihaz hafızası) */
    if (profile != NULL && profile->has_saved) {
        for (i = 0u; i < count; i++) {
            if (caps_list[i].backend == profile->saved_backend &&
                profile->saved_rate <= caps_list[i].max_rate) {
                sel.backend = profile->saved_backend;
                sel.rate = profile->saved_rate;
                sel.from_saved = 1;
                return sel;
            }
        }
    }

    /* 2) En yüksek SR'lı uygun cihaz (K5) */
    for (i = 0u; i < count; i++) {
        if (caps_list[i].supports_f32 && caps_list[i].max_rate > best_rate) {
            best_rate = caps_list[i].max_rate;
            best_i = i;
        }
    }
    if (best_i != (size_t)-1) {
        sel.backend = caps_list[best_i].backend;
        sel.rate = best_rate;
        return sel;
    }

    /* 3) Varsayılan (K4: 48 kHz) */
    return sel;
}
```

Not: backend enum **seçim/planlama** katmanındadır; gerçek API çağrıları `os/01–04`
dosyalarındadır (ASIO SDK · WASAPI COM · `snd_pcm_*` · CoreAudio AUHAL).

## §8 Dile özel notlar (C11)

| Başlık | Not |
|---|---|
| **Standart** | ISO/IEC 9899:2018 (**C11**) — `<stdatomic.h>` (N1570 §7.17), `_Atomic`, `memory_order_*` |
| **Bağımlılık** | **Yalnız standart kütüphane**: `<math.h> <stdint.h> <stddef.h> <stdio.h> <string.h> <stdatomic.h> <stdbool.h>` — harici paket YOK. `gcc`/`clang`'de `-lm` (libm) gerekir. |
| **Derleme (tek dosya)** | `gcc -std=c11 -O2 neva_examples.c -lm -o neva_examples` |
| **const-correctness** | Sabit girdi `const *`; yardımcılar `static inline` (dışa açılmaz — MISRA §8.x ruhu) |
| **NULL** | C'de `nullptr` YOK → `NULL` (`<stddef.h>`); imleç karşılaştırmaları açık |
| **MISRA dostu** | Kısa fonksiyonlar, tek dönüş noktalı doğrulama, `switch`'te `default` zorunlu, goto YOK, dinamik tahsis RT yolunda YOK |
| **Pitfall — atomikler** | `size_t` atomiğinin **lock-free garantisi standartta zorunlu değil** → (`atomic_is_lock_free()` init'te kontrol edilir; x86-64/ARM64'te pratikte lock-free). `volatile` atomik yerine **geçmez**. ⚠️ MSVC C-modu `<stdatomic.h>` desteği sürüm-spesifik → **⚠️ VERIFICATION REQUIRED** (referans derleyici gcc/Clang). |
| **Pitfall — kayan nokta** | Çift hassasiyet fonksiyonlarına (`cos`, `exp`, `log10`) düşmeyin — `f` sonekli (`cosf`, `expf`, `powf`); K2 zinciri tek hassasiyet (32f) kalır, `double` karışımı gizli dönüşüm yaratır. |
| **Pitfall — denormaller** | `expf` tabanlı envelope `0'a` yaklaşırken denormal üretir (CPU yavaşlar) — üretimde `env < 1e-9f → 0` flush eklenir (⚠️ denorm-flag/spi kütüphaneye göre doğrulanır). |
| **Bit-perfect (K6)** | Örneklerde dönüşüm yok; SR eşit + float32 ise zincir `memcpy` düzeyinde kimlik geçer. |
| **WAV** | Little-endian host varsayımı (x86/ARM64 LE); big-endian hedef **⚠️ VERIFICATION REQUIRED** (bayt çevirme eklenmeli). |
