## §1 Bağlam — Neva Engine + Go

Neva Engine'in DSP çekirdeği C++20/JUCE'tadır; **Go'nun bağlamı** yerel servis / MCP
köprüsüdür: engine kontrol plane'ine (WS/REST JSON) aracılık eden, cihaz profil dosyalarını
yöneten ve offline doğrulama araçlarını taşıyan tek binary. Bağlayıcı I/O sözleşmesi
(doc 10 — SSOT):

| Kural | İçerik |
|---|---|
| K1 | Input **32-bit float** |
| K2 | Internal processing **32-bit float** |
| K3 | Output **32-bit float**; 24-bit int düşüşünde **TPDF dither** |
| K4 | SR **44.1–192 kHz** — varsayılan **48 kHz** |
| K5 | Cihaz 192 sunmuyorsa **en yüksek yerel SR** |
| K6 | Bit-perfect = **SR eşit + float32** |

Go tarafı gerçek zamanlı ses **yürümez** (realtime audio Go'da GC jitter nedeniyle
güvenilir değildir — dürüst sınır: DSP C++ çekirdekte); buradaki örnekler servis/araç
katmanıdır: profil dosyası I/O, kuyruk testi, offline doğrulama.

**Dil standartları (global AGENTS.md):** stdlib-only (bağımlılık YOK) · `err != nil`
her açık · gofmt biçimi · `context.Context` iptal zinciri · generics gereksiz → basit
tipler · `sync/atomic` doğru tipler (`atomic.Uint64` — Go 1.19+).

Ornek paket başlığı (hepsi `package main`):

```go
// Neva yerel servis örnekleri — araştırma MD, derlenmedi.
// stdlib-only: bytes, encoding/binary, errors, fmt, io, math, os, runtime, sync/atomic.
package main
```

satırları tek `package main` dosyasında birleştirilir (import bloğu tek, sıralama
gofmt'de alfabetiktir).

## §2 Örnek 1 — Biquad EQ (R16 çift form · K2)

RBJ peaking EQ katsayıları + Direct Form I; 48 kHz referans (K4). R16: parametrik ve
grafik (31 bant) EQ aynı `BiquadPeaking` motorunu çağırır.

```go
import "math"

// BiquadPeaking RBJ peaking EQ — Direct Form I (K2: internal 32f).
type BiquadPeaking struct {
	b0, b1, b2, a1, a2 float64
	x1, x2, y1, y2     float64
}

// SetPeaking katsayıları hesaplar (RBJ Audio EQ Cookbook) — 48k dahil her K4 SR.
func (b *BiquadPeaking) SetPeaking(sampleRate, freq, q, gainDB float64) {
	a := math.Pow(10, gainDB/40)              // A = 10^(dB/40)
	w0 := 2 * math.Pi * freq / sampleRate     // radyan/ornek
	cosW0 := math.Cos(w0)
	alpha := math.Sin(w0) / (2 * q)           // bandwidth term

	b0 := 1 + alpha*a
	b1 := -2 * cosW0
	b2 := 1 - alpha*a
	a0 := 1 + alpha/a
	a1 := -2 * cosW0
	a2 := 1 - alpha/a

	b.b0, b.b1, b.b2 = b0/a0, b1/a0, b2/a0 // a0'a bölme (normalizasyon)
	b.a1, b.a2 = a1/a0, a2/a0
	b.x1, b.x2, b.y1, b.y2 = 0, 0, 0, 0    // pop önleme — durum sıfırlama
}

// Process tek kanallı buffer'ı işler; dst ve src aynı uzunlukta olmalı.
// Direct Form I: y[n] = b0·x[n] + b1·x[n−1] + b2·x[n−2] − a1·y[n−1] − a2·y[n−2]
func (b *BiquadPeaking) Process(dst, src []float32) {
	for i := range src {
		x := float64(src[i])
		y := b.b0*x + b.b1*b.x1 + b.b2*b.x2 - b.a1*b.y1 - b.a2*b.y2
		b.x2, b.x1 = b.x1, x
		b.y2, b.y1 = b.y1, y
		dst[i] = float32(y)
	}
}
```

## §3 Örnek 2 — 32f Buffer Döngüsü (K2 · K4 · K5)

48 kHz varsayılan (K4), cihaz 192 sunmuyorsa en yüksek yerel SR (K5), `[]float32`
(interleaved) buffer üzerinde allocation-sız döngü (K2).

```go
// DefaultSampleRate K4 varsayılanı.
const DefaultSampleRate = 48000

// SupportedRates K4 destek listesi — üst sınır 192 kHz.
var SupportedRates = []int{44100, 48000, 88200, 96000, 176400, 192000}

// ResolveChainRate K5: cihaz 192 sunmuyorsa en yüksek yerel SR;
// 44.1 altı cihaz → 44.1 kHz (en düşük destek).
func ResolveChainRate(deviceMax int) int {
	best := 0
	for _, r := range SupportedRates {
		if r <= deviceMax && r > best {
			best = r
		}
	}
	if best == 0 {
		return SupportedRates[0] // 44.1 kHz
	}
	return best
}

// IsBitPerfect K6: bit-perfect kapısı — SR eşit + float32.
func IsBitPerfect(sourceRate, deviceRate int) bool {
	return sourceRate == deviceRate // format float32 varsayılır (K1-K3)
}

// ApplyGain K2: interleaved float32 buffer kazancı — allocation yok.
func ApplyGain(buf []float32, gain float32) {
	for i := range buf {
		buf[i] *= gain
	}
}
```

## §4 Örnek 3 — SPSC Ring Buffer (R10 · K2)

Kanal yerine **atomik head/tail** SPSC: `head` yalnız yazıcı, `tail` yalnız okuyucu
yazar; buffer baştan allocate edilir. Go 1.19+ `sync/atomic` atomik tipleri
(`atomic.Uint64`) kullanılır — Go bellek modeli atomikleri sıralı-tutarlı (seq-cst)
olarak tanımlar, ayrı fence gerekmez.

Alternatif "tek goroutine sahipli" deseni: audio callback yerel `[]float32`'sine yazar,
payload **kopyalanmış** olarak `chan []float32` (buffer tahsisi callback dışında) ile
servis goroutine'ine gönderilir — kanal kendisi kuyruk, ring buffer'a gerek yok.
Gerçek zamanlı yol yine C++ çekirdektedir; bu örnek servis/test katmanı.

```go
import (
	"fmt"
	"sync/atomic"
)

// SpscRing lock-free SPSC ring buffer (R10) — tek yazıcı, tek okuyucu.
// Boyut 2'nin kuvveti olmalı (mask hesabı için). Go 1.19+ atomik tipleri.
type SpscRing struct {
	buf  []float32
	mask uint64
	head atomic.Uint64 // yalnız yazıcı yazar
	tail atomic.Uint64 // yalnız okuyucu yazar
}

// NewSpscRing power-of-2 boyutlu ring oluşturur.
func NewSpscRing(powerOfTwo int) (*SpscRing, error) {
	if powerOfTwo < 2 || powerOfTwo&(powerOfTwo-1) != 0 {
		return nil, fmt.Errorf("boyut 2'nin kuvveti olmalı: %d", powerOfTwo)
	}
	return &SpscRing{
		buf:  make([]float32, powerOfTwo), // baştan allocate — RT kuralı
		mask: uint64(powerOfTwo - 1),
	}, nil
}

// TryWrite doluysa false döner (yazıcı çağırır).
func (r *SpscRing) TryWrite(v float32) bool {
	h := r.head.Load()
	next := (h + 1) & r.mask
	if next == r.tail.Load() {
		return false // dolu
	}
	r.buf[h] = v          // önce veri
	r.head.Store(next)    // sonra index yayını (happens-after)
	return true
}

// TryRead boşsa false döner (okuyucu çağırır).
func (r *SpscRing) TryRead() (float32, bool) {
	t := r.tail.Load()
	if t == r.head.Load() {
		return 0, false // boş
	}
	v := r.buf[t]
	r.tail.Store((t + 1) & r.mask)
	return v, true
}
```

## §5 Örnek 4 — WAV 32f Okuma/Yazma (K3 · K1)

RIFF header + `fmt` chunk `AudioFormat = 3` (WAVE_FORMAT_IEEE_FLOAT) + 32 bit;
`encoding/binary` little-endian parse; SR K4 listesiyle doğrulanır. Bilinmeyen chunk'lar
(`LIST`, `fact` vb.) atlanır; chunk'lar word-aligned olduğundan tek baytlık pad'e dikkat.

```go
import (
	"bytes"
	"encoding/binary"
	"errors"
	"fmt"
	"io"
	"os"
)

// wavFmt fmt chunk gövdesi (16 bayt).
type wavFmt struct {
	AudioFormat   uint16 // 3 = IEEE_FLOAT (K3)
	NumChannels   uint16
	SampleRate    uint32
	ByteRate      uint32
	BlockAlign    uint16
	BitsPerSample uint16
}

// wavAllowedRates K4 izin listesi — 192 kHz'e kadar.
var wavAllowedRates = []int{44100, 48000, 88200, 96000, 176400, 192000}

// ReadWav32 RIFF + format 3 (IEEE_FLOAT) 32f WAV okur (K3/K1).
// Dönüş: interleaved samples, sampleRate, channels.
func ReadWav32(path string) ([]float32, int, int, error) {
	data, err := os.ReadFile(path)
	if err != nil {
		return nil, 0, 0, fmt.Errorf("wav oku: %w", err)
	}
	if len(data) < 44 || string(data[0:4]) != "RIFF" || string(data[8:12]) != "WAVE" {
		return nil, 0, 0, errors.New("RIFF/WAVE değil")
	}

	r := bytes.NewReader(data[12:]) // RIFF/WAVE ID'leri atlandı
	var (
		fmtOK, dataOK bool
		channels      int
		sampleRate    int
		samples       []float32
	)

	for {
		var id [4]byte
		var size uint32
		if _, err := binary.Read(r, binary.LittleEndian, &id); err != nil {
			break // chunk sınırı — normal sonlanma (io.EOF)
		}
		if err := binary.Read(r, binary.LittleEndian, &size); err != nil {
			return nil, 0, 0, errors.New("chunk size okunamadı")
		}

		switch string(id[:]) {
		case "fmt ":
			var f wavFmt
			if err := binary.Read(r, binary.LittleEndian, &f); err != nil {
				return nil, 0, 0, fmt.Errorf("fmt chunk: %w", err)
			}
			if size > 16 { // cbSize vb. — atla
				if _, err := r.Seek(int64(size-16), io.SeekCurrent); err != nil {
					return nil, 0, 0, err
				}
			}
			if f.AudioFormat != 3 || f.BitsPerSample != 32 {
				return nil, 0, 0,
					fmt.Errorf("beklenen format 3/32bit, gelen %d/%d", f.AudioFormat, f.BitsPerSample)
			}
			channels, sampleRate = int(f.NumChannels), int(f.SampleRate)
			fmtOK = true
		case "data":
			n := int(size / 4) // 4 bayt/örnek (32f)
			samples = make([]float32, n)
			if err := binary.Read(r, binary.LittleEndian, samples); err != nil {
				return nil, 0, 0, fmt.Errorf("data chunk: %w", err)
			}
			dataOK = true
		default:
			if _, err := r.Seek(int64(size), io.SeekCurrent); err != nil {
				return nil, 0, 0, err
			}
		}
		if size%2 == 1 { // word-pad — chunk çift bayta hizalanır
			r.Seek(1, io.SeekCurrent)
		}
	}

	if !fmtOK || !dataOK {
		return nil, 0, 0, errors.New("fmt/data chunk eksik")
	}
	rateOK := false
	for _, r := range wavAllowedRates {
		if r == sampleRate {
			rateOK = true
			break
		}
	}
	if !rateOK {
		return nil, 0, 0, fmt.Errorf("SR %d K4 listesinde yok", sampleRate)
	}
	return samples, sampleRate, channels, nil
}

// WriteWav32 32f WAV yazar — format 3 header (K3).
func WriteWav32(path string, samples []float32, sampleRate, channels int) error {
	dataSize := uint32(len(samples) * 4)
	buf := new(bytes.Buffer)
	// NOT: header binary.Write çağrıları bytes.Buffer'a yazdığı için hata üretmez
	// (dürüst kısaltma); errcheck geçişinde üretilecek şekilde sarmalanabilir.
	buf.WriteString("RIFF")
	binary.Write(buf, binary.LittleEndian, uint32(36)+dataSize) // header 36 + data
	buf.WriteString("WAVE")
	buf.WriteString("fmt ")
	binary.Write(buf, binary.LittleEndian, uint32(16))          // fmt chunk boyutu
	binary.Write(buf, binary.LittleEndian, uint16(3))           // WAVE_FORMAT_IEEE_FLOAT (K3)
	binary.Write(buf, binary.LittleEndian, uint16(channels))
	binary.Write(buf, binary.LittleEndian, uint32(sampleRate))
	binary.Write(buf, binary.LittleEndian, uint32(sampleRate*channels*4)) // byte rate
	binary.Write(buf, binary.LittleEndian, uint16(channels*4))            // block align
	binary.Write(buf, binary.LittleEndian, uint16(32))                    // bit depth
	buf.WriteString("data")
	binary.Write(buf, binary.LittleEndian, dataSize)
	if err := binary.Write(buf, binary.LittleEndian, samples); err != nil {
		return fmt.Errorf("data yaz: %w", err)
	}
	return os.WriteFile(path, buf.Bytes(), 0o644)
}
```

## §6 Örnek 5 — Compressor + Brickwall Limiter (R10 · K3)

Peak envelope (tek kutuplu, attack/release) → hard-knee 4:1 → −12 dB eşik → 0 dBFS
brickwall clamp. K3: 24-bit int düşüşünde TPDF dither eklenir; float32 çıkışta dither
**yok** (K6 bit-perfect).

```go
import "math"

// CompressorLimiter R10: envelope + brickwall limiter (K3).
type CompressorLimiter struct {
	ThresholdDB float64 // -12 dB
	Ratio       float64 // 4:1
	attackCoef  float64
	releaseCoef float64
	env         float64 // peak envelope (linear)
}

// NewCompressorLimiter attack/release katsayılarını SR'den türetir:
// katsayı = exp(−1 / (τ·sr)) — tek zaman sabitli tek kutuplu envelope.
func NewCompressorLimiter(sampleRate int, attackMs, releaseMs float64) *CompressorLimiter {
	return &CompressorLimiter{
		ThresholdDB: -12,
		Ratio:       4,
		attackCoef:  math.Exp(-1 / (attackMs / 1000 * float64(sampleRate))),
		releaseCoef: math.Exp(-1 / (releaseMs / 1000 * float64(sampleRate))),
	}
}

// Process buffer'ı yerinde işler: kompresör + brickwall clamp.
func (c *CompressorLimiter) Process(buf []float32) {
	for i, s := range buf {
		x := float64(s)
		abs := math.Abs(x)
		if abs > c.env {
			c.env = c.attackCoef*c.env + (1-c.attackCoef)*abs
		} else {
			c.env = c.releaseCoef*c.env + (1-c.releaseCoef)*abs
		}

		gain := 1.0
		if c.env > 0 {
			levelDB := 20 * math.Log10(c.env)
			if over := levelDB - c.ThresholdDB; over > 0 {
				// hard-knee 4:1: eşiği aşan her dB için 0.25 dB çıkış
				outDB := c.ThresholdDB + over/c.Ratio
				gain = math.Pow(10, (outDB-levelDB)/20)
			}
		}

		y := x * gain
		switch { // brickwall limiter: 0 dBFS clamp (K3)
		case y > 1:
			y = 1
		case y < -1:
			y = -1
		}
		buf[i] = float32(y)
	}
}
```

## §7 Örnek 6 — OS/Cihaz Enum Otomatik Varsayılan (R18)

R18: global sabit varsayılan **YOK** — varsayılanlar cihaz yeteneğinden otomatik
tespit edilir. `runtime.GOOS` switch OS varsayılan backend'ini verir; cihaz bazlı
profil OS device API'sinden gelen `DeviceCaps` ile çözülür.

```go
import "runtime"

// Backend OS varsayılan audio backend'i.
type Backend string

const (
	BackendUnknown   Backend = "unknown"
	BackendWASAPI    Backend = "wasapi"    // Windows
	BackendCoreAudio Backend = "coreaudio" // macOS
	BackendALSA      Backend = "alsa"      // Linux (PipeWire ALSA API üzerinden)
)

// DefaultBackend R18 — OS varsayılan backend seçimi.
func DefaultBackend(goos string) Backend {
	switch goos {
	case "windows":
		return BackendWASAPI
	case "darwin":
		return BackendCoreAudio
	case "linux":
		return BackendALSA
	default:
		return BackendUnknown
	}
}

// DeviceCaps OS device-change sorgusundan gelir (R18).
type DeviceCaps struct {
	ID            string
	MaxSampleRate int
	MaxChannels   int
}

// ResolveProfile cihaz yeteneğine göre otomatik varsayılan (K4+K5+R18).
// Dönüş: OS varsayılan backend + zincir SR (K5 fallback uygulanmış).
// NOT: bufferFrames gerçek R18'de cihaz gecikme raporundan seçilir —
// 512 burada yalnız örnektir; "global sabit varsayılan" R18'de yasaktır.
func ResolveProfile(caps DeviceCaps) (Backend, int) {
	chainRate := ResolveChainRate(caps.MaxSampleRate) // K5
	return DefaultBackend(runtime.GOOS), chainRate
}
```

## §8 Dile Özel Notlar (Go)

1. **stdlib-only**: `bytes` · `encoding/binary` · `errors` · `fmt` · `io` · `math` ·
   `os` · `runtime` · `sync/atomic` — dış bağımlılık YOK.
2. **`err != nil`**: her açık hata döndüren çağrı kontrol edilir; sarmalama `%w` ile
   (kök neden korunur).
3. **Atomik tipler**: `atomic.Uint64` Go 1.19+ — eski `atomic.AddUint64(&x, 0)` trick'i
   gerekmez; bellek modeli atomikleri seq-cst tanımlar.
4. **Generics gereksiz**: ring/biquad somut `float32` ile yazılır — jenerik soyutlama
   YAGNI (gerekçe: tek eleman tipi, ölçüm kanıtlanmış desen).
5. **gofmt**: tüm dosyalar `gofmt -l` boş dönmeli; tab yerine space.
6. **GC & realtime**: Go servis katmanıdır; audio callback C++ çekirdektedir. Ring buffer
   `make` ile baştan allocate edilir — döngü içi tahsis yok.
7. **İsimlendirme**: export edilen (`BiquadPeaking`, `ResolveChainRate`) ve
   export edilmeyen (`wavFmt`) ayrımı paket sınırını korur.
