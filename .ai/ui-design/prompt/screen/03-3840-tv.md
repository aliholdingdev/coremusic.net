# Prompt: 3840×2160 4K TV Screen

Bu prompt, CoreMusic UI Designer agent'ı tarafından **3840×2160 çözünürlükteki 4K Smart TV ekranları** için CSS/HTML üretimi yaparken kullanılır.

---

## 1. Platform Tanımı

| Özellik | Değer |
|---------|-------|
| Çözünürlük | 3840×2160 (4K UHD) |
| Cihaz | Samsung, LG, Sony 4K Smart TV |
| İşletim Sistemi | Tizen, webOS, Android TV, tvOS |
| Giriş Yöntemi | Uzaktan kumanda (D-pad: ↑↓←→, OK, Back, Home) |

## 7. Hover Davranışı

**Hover YOKTUR.** Navigasyon D-pad (focus tabanlı) ile yapılır.

```css
/* Hover state'leri devre dışı */
*:hover {
  /* Boş — hover efekti uygulanmaz */
}

/* Sadece focus / focus-visible */
*:focus {
  outline: 3px solid var(--accent);
  outline-offset: 4px;
  box-shadow: 0 0 20px var(--accent-glow);
}

*:focus-visible {
  outline: 3px solid var(--accent);
  outline-offset: 4px;
  box-shadow: 0 0 20px var(--accent-glow);
}

/* Focus animasyonu */
*:focus {
  animation: focus-glow 2s ease-in-out infinite;
}

@keyframes focus-glow {
  0%, 100% { box-shadow: 0 0 20px var(--accent-glow); }
  50% { box-shadow: 0 0 30px var(--accent-glow); }
}
```

**Kural:** `@media (hover: hover)` blokları kullanılmaz. TV'de hover hiçbir zaman aktif değildir.

### 8.2 D-pad Navigasyon JavaScript

```javascript
// TV D-pad navigasyon helper'ı
function initDpadNavigation() {
  const focusable = document.querySelectorAll(
    'a, button, input, [tabindex]:not([tabindex="-1"]), [role="button"]'
  );

  let currentIndex = 0;

  document.addEventListener('keydown', (e) => {
    switch (e.key) {
      case 'ArrowRight':
        e.preventDefault();
        currentIndex = Math.min(currentIndex + 1, focusable.length - 1);
        focusable[currentIndex].focus();
        break;
      case 'ArrowLeft':
        e.preventDefault();
        currentIndex = Math.max(currentIndex - 1, 0);
        focusable[currentIndex].focus();
        break;
      case 'ArrowDown':
        e.preventDefault();
        // Grid'de bir sonraki satıra geç
        const cols = getGridColumns();
        currentIndex = Math.min(currentIndex + cols, focusable.length - 1);
        focusable[currentIndex].focus();
        break;
      case 'ArrowUp':
        e.preventDefault();
        const colsUp = getGridColumns();
        currentIndex = Math.max(currentIndex - colsUp, 0);
        focusable[currentIndex].focus();
        break;
      case 'Enter':
      case ' ':
        e.preventDefault();
        focusable[currentIndex].click();
        break;
      case 'Escape':
      case 'Backspace':
        e.preventDefault();
        window.history.back();
        break;
    }
  });
}
```

## 9. CSS Üretim Talimatları

### 9.1 Agent Talimatı

```
Bu prompt'u kullanarak 3840×2160 4K TV ekran için CSS üret.
Tüm stiller bu dosyadaki token değerlerini kullanmalı.
D-pad navigasyonu desteklenmeli.
10ft UI kurallarına uygun font boyutları.
Performans için düşük blur kullan.
```

### 9.2 Zorunlu CSS Yapıları

1. **Reset:** `*, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; }`
2. **Body:** `overflow-x: hidden; background: var(--bg-primary); color: var(--text-primary); padding: var(--tv-overscan);`
3. **Scroll Behavior:** `html { scroll-behavior: smooth; }`
4. **Selection:** `::selection { background: var(--accent); color: white; }`
5. **Scrollbar:** TV'de scroll bar gizlenir: `scrollbar-width: none;`
6. **D-pad Focus:** Tüm interaktif elemanlarda focus-visible
7. **No Hover:** Hover state'leri devre dışı
8. **Overscan:** Kenar boşlukları uygulanmış
9. **Performance:** Düşük blur, basit animasyonlar

### 9.3 Yasak Örüntüleri

| ❌ Yasak | ✅ Doğru |
|----------|----------|
| `hover:` medya sorgusu | Sadece `focus` / `focus-visible` |
| `blur(20px)` | `blur(4px)` veya yok |
| `vw/vh` birimleri (header/footer) | `px` birimleri |
| `font-size < 24px` | Min `24px` (10ft) |
| Animasyon < 300ms | Min `300ms` |
| `cursor: pointer` | Gerekmez (fare yok) |
| Parallax efekti | Yasak |
