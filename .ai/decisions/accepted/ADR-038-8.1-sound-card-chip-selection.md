# ADR-038: 8.1 Sound Card Chip Selection

**Status:** Active (güncellenebilir)
**Kategorisi:** Audio Hardware
**İlgili Agent:** [[.agents/embedded-engineer]]
**İlgili Division:** Hardware Division + Software Division

---

## 1. Amaç

Bu ADR, CoreMusic platformunun 8.1 surround ses donanımı için DAC (Digital-to-Analog Converter) çip seçimini, XMOS XU316 USB Audio Class 2.0 arabirimiyle entegrasyonunu ve PCM5122'nin neden reddedildiğini (H001) tanımlar. Karar, donanım tasarımından yazılım sürücülerine kadar tüm ses zincirini etkiler.

CoreMusic'in 8.1 surround ses hedefi:
- 8 kanal analog çıkış + 1 LFE (Low Frequency Effects) subwoofer kanalı
- 24-bit / 192kHz max sample rate
- SNR ≥ 112dB ( PCM3168A ) veya ≥ 120dB ( AK4458 opsiyonel )
- Latency < 10ms (ASIO), < 20ms (WASAPI)
- Class AB amplifikatör entegrasyonu (100W @ 8Ω, THD+N < 0.01%)

## 2. Bağlam

### 2.1 Mevcut Durum

CoreMusic, araç içi bilgi-eğlence, ev medya merkezi ve profesyonel stüdyo için çoklu kanal ses çıkışına ihtiyaç duyar. 8.1 surround, 7.1 surround'a ek olarak iki yükseklik kanalı (Height L/R) içerir:

| Kanal | Frekans Aralığı | Amaç |
|-------|-----------------|------|
| Front Left / Right | 20Hz – 20kHz | Ana stereo çıkış |
| Center | 100Hz – 8kHz | Diyalog |
| Surround Left / Right | 100Hz – 16kHz | Ambient ses |
| Rear Left / Right | 100Hz – 16kHz | Arka plan |
| Height Left / Right | 200Hz – 16kHz | Yükseklik efektleri |
| Subwoofer (LFE) | 20Hz – 120Hz | Bass management |

## 3. Karar

CoreMusic'te **PCM3168A + XMOS XU316** kombinasyonu kullanılacak. **PCM5122 kesinlikle reddedilmiştir (H001).**

### 3.1 Red Kararı: PCM5122 (H001)

| # | Gerekçe | Açıklama |
|---|---------|----------|
| 1 | Kanal yetersizliği | PCM5122 sadece 2 kanal çıkış destekler |
| 2 | 8.1 uyumsuzluğu | 8.1 surround için minimum 8 kanal gerekli |
| 3 | Upsampling imkansız | Yazılımsal upmix kalite kaybına yol açar |
| 4 | Donanım kilidi | PCM5122 donanımsal olarak 2 kanala sabitlenmiş |
| 5 | Alternatif mevcut | PCM3168A aynı fiyat aralığında 8 kanal sunar |

**H001 Uyarısı:** PCM5122 ile 8.1 surround YAPILAMAZ. Sadece 2 kanal destekler. Herhangi bir tasarımda PCM5122 kullanımı tespit edilirse derhal PCM3168A veya AK4458 ile değiştirilmelidir.

### 3.2 Kabul Kararı: PCM3168A

| Özellik | PCM3168A Değeri |
|---------|-----------------|
| Kanal Sayısı | 8 (8.1 surround uyumlu) |
| Bit Derinliği | 24-bit |
| Max Sample Rate | 192kHz |
| SNR | 112dB |
| THD+N | -98dB |
| Güç Tüketimi | Düşük (150mW/kanal) |
| paket | TSSOP-20 |
| Çalışma Sıcaklığı | -40°C – 85°C |

### 3.3 Opsiyonel Karar: AK4458

| Özellik | AK4458 Değeri |
|---------|---------------|
| Kanal Sayısı | 8 |

### 4.2 XMOS XU316 ile Bağlantı

```
XMOS XU316                    PCM3168A
┌─────────────┐              ┌─────────────┐
│ USB Type B  │              │ SCK (Pin 11)│
│  ↓          │              │ BCK (Pin 12)│
│ UAC 2.0     │──I2S/DMX───▶│ LRCK(Pin 13)│
│ Engine      │              │ DIN1(Pin 14)│
│  ↓          │              │ DIN2(Pin 15)│
│ DSP Core    │              │ DIN3(Pin 16)│
│ (Zero-Lat)  │              │ DIN4(Pin 17)│
└─────────────┘              └─────────────┘
```

### 4.4 ASIO Buffer Ayarları

| Buffer Boyutu | Gecikme (ms) | CPU Kullanımı | Kullanım |
|--------------|--------------|---------------|----------|
| 64 sample | ~1.33ms | Yüksek | Profesyonel kayıt |
| 128 sample | ~2.67ms | Orta-Yüksek | Düşük gecikme |
| 256 sample | ~5.33ms | Orta | Genel kullanım |
| 512 sample | ~10.67ms | Düşük | Varsayılan |
| 1024 sample | ~21.33ms | Çok Düşük | Yüksek kalite |

**Varsayılan:** 512 sample @ 48kHz = ~10.67ms gecikme.

### 4.5 WASAPI Exclusive Mode

WASAPI Exclusive Mode, uygulamaya ses kartı üzerinde tam kontrol sağlar ancak:
- Aynı anda sadece tek uygulama Exclusive Mode kullanabilir
- Diğer uygulamalar share mode'a düşer
- Fallback: Shared Mode (WASAPI) → Normal kullanım

### 4.8 DSP Chain Sırası

```
PCM → ADC → Equalizer → Compressor → Limiter → Bass Management → DAC → Amplifikatör → Hoparlör
```

Her kanal için bağımsız DSP zinciri çalışır. Zero-allocation kuralı geçerli (ADR-017).
