# 16. REWRITE PROCESS

Bir dosyayı yeniden yazmadan önce aşağıdaki workflow zorunludur.

## STEP 1 — READ

Mevcut dosyayı tamamen oku.

## STEP 2 — ANALYZE

Şunları belirle:

- Purpose
- Scope
- Dependencies
- References
- Authority
- Existing Rules
- Architecture Rules
- Agent Ownership

## STEP 3 — DETECT

Kontrol et:

- Missing sections
- Duplicate information
- Contradictions
- Outdated information
- Broken references
- Wrong ownership
- Architecture violations
- SSOT violations
- Ambiguous instructions
- Unnecessary complexity

## STEP 4 — PLAN

Değişiklik planı oluştur.

Plan:

```text
Current State
↓
Problem
↓
Root Cause
↓
Required Change
↓
Affected Files
↓
Risk
↓
Validation
```

## STEP 5 — REWRITE

Dosyayı yeniden yaz.

Ancak:

> Mevcut anlamı ve geçerli requirements'ı koru.

## STEP 6 — REFERENCE VALIDATION

Kontrol et:

- Internal links
- File references
- Agent references
- Template references
- Architecture references
- Authority references

## STEP 7 — INDEX UPDATE

Gerekliyse:

```text

glossary.md
```

güncellenir.

## STEP 8 — CHANGE LOG

