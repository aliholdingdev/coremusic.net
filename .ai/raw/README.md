# raw/ — Ham Kaynaklar

- Bu klasör **ham kaynak içindir**: makale, transkript, not, PDF, web klibi.
- Buradaki dosyalar **değiştirilmez, silinmez, sadece okunur**.
- Yeni kaynak eklenince **INGEST** işlemi çalıştırılır (bkz. `../CLAUDE.md` §8; sonuç örnek: [[test-kaynak]] → [[ai-agent-memory]]).
- Ingest tamamlanmadan `sources/özet.md` güncellenmez; güncellenmeden ingest bitmiş sayılmaz (bkz. `../CLAUDE.md` §9).
