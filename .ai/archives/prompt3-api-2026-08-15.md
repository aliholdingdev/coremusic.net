## 3. API Gateway

*Detaylı metadata: [[ADR-084]]*

### 3.1 Gateway Nedir?

Tüm istemcilerin tek giriş noktası `api.coremusic.net`'tir. Gateway; routing, auth, rate limit, validation, logging, correlation ID görevini üstlenir.

### 3.2 Gateway Görevleri

| # | Görev | Açıklama |
|---|-------|----------|
| 1 | Routing | İsteği doğru servise yönlendirme |
| 2 | Authentication | JWT / API Key doğrulama |
| 3 | Authorization | RBAC yetki kontrolü |
| 4 | Rate Limiting | İstek sınırlaması |
| 5 | Validation | Request/Response validasyonu |
| 6 | Logging | Yapılandırılmış loglama |
| 7 | Correlation ID | İstek takibi |
| 8 | Error Handling | Standart hata formatı |
| 9 | Response Format | Standart yanıt formatı |
| 10 | Caching | Cache headers |

### 3.3 Gateway Akışı

```
Client Request → api.coremusic.net
  → Authentication (JWT/API Key)
    → Authorization (RBAC)
      → Rate Limit Check
        → Request Validation
          → Route to Service
            → Service Processing
              → Response Validation
                → Log + Correlation ID
                  → Client Response
```

### 3.4 Gateway Kodu

```php
<?php

declare(strict_types=1);

namespace CoreMusic\Api\Gateway;

final class ApiGateway
{
    public function __construct(
        private readonly RouterInterface $router,
        private readonly AuthMiddleware $auth,
        private readonly RateLimitMiddleware $rateLimit,
        private readonly ValidationMiddleware $validation,
        private readonly LoggerInterface $logger,
    ) {}

    public function handle(ServerRequestInterface $request): ResponseInterface
    {
        $correlationId = $this->generateCorrelationId();
        
        $request = $request->withAttribute('correlation_id', $correlationId);
        
        try {
            $request = $this->auth->process($request);
            $request = $this->rateLimit->process($request);
            $request = $this->validation->process($request);
            
            $response = $this->router->dispatch($request);
            
            $this->logger->info('API Request', [
                'correlation_id' => $correlationId,
                'method' => $request->getMethod(),
                'path' => $request->getUri()->getPath(),
                'status' => $response->getStatusCode(),
            ]);
            
            return $response;
        } catch (\Throwable $e) {
            $this->logger->error('API Error', [
                'correlation_id' => $correlationId,
                'error' => $e->getMessage(),
            ]);
            
            return $this->errorResponse($e);
        }
    }
}
```

## 4. BFF (Backend for Frontend)

*Detaylı metadata: [[ADR-084]]*

### 4.1 BFF Nedir?

Her istemci tipi kendi BFF'sini kullanır. BFF, istemciye özel response formatı sağlar.

### 4.2 BFF Tablosu

| İstemci | BFF | Response |
|---------|-----|----------|
| SPA | SPA BFF | Tam veri |
| Mobile | Mobile BFF | Minimal |
| Embedded (RPi5) | Embedded BFF | Ultra-minimal, gzip |
| Desktop | Desktop BFF | Orta boy |
| Admin | Admin BFF | Full + audit |
| Car | Car BFF | Touch-optimized |

### 4.3 BFF Kodu

```php
<?php

declare(strict_types=1);

namespace CoreMusic\Api\BFF;

interface BFFInterface
{
    public function format(array $data): array;
}

final class SpaBFF implements BFFInterface
{
    public function format(array $data): array
    {
        return [
            'data' => $data,
            'meta' => [
                'timestamp' => time(),
                'version' => '1.0',
            ],
        ];
    }
}

final class MobileBFF implements BFFInterface
{
    public function format(array $data): array
    {
        // Minimal format — sadece gerekli alanlar
        return array_intersect_key($data, array_flip(['id', 'title', 'url']));
    }
}

final class EmbeddedBFF implements BFFInterface
{
    public function format(array $data): array
    {
        // Ultra-minimal — gzip ile squeeze
        return [
            'd' => $data['id'] ?? null,
            't' => $data['title'] ?? null,
        ];
    }
}
```

## 5. CQRS (Command Query Responsibility Segregation)

*Detaylı metadata: [[ADR-086]], [[../../brain.md]] §4B*

### 5.1 CQRS Nedir?

Yazma (Command) ve okuma (Query) işlemleri tamamen ayrılır:

```
Write: Command → Use Case → Repository → MySQL Master
Read:  Query → Read Model → Cache → Response
```

### 5.2 Write Tarafı (Command)

```php
<?php

declare(strict_types=1);

namespace CoreMusic\Music\Application\Command;

final class AddAlbumCommand
{
    public function __construct(
        public readonly string $title,
        public readonly string $artistId,
        public readonly array $tracks,
    ) {}
}

final class AddAlbumHandler
{
    public function __construct(
        private readonly AlbumRepositoryInterface $repository,
        private readonly EventDispatcherInterface $dispatcher,
    ) {}

    public function handle(AddAlbumCommand $command): Album
    {
        $album = Album::create(
            title: new Title($command->title),
            artistId: ArtistId::from($command->artistId),
        );

        $this->repository->save($album);
        
        $this->dispatcher->dispatch(new AlbumAddedEvent(
            albumId: $album->getId(),
            title: $command->title,
        ));

        return $album;
    }
}
```

### 5.3 Read Tarafı (Query)

```php
<?php

declare(strict_types=1);

namespace CoreMusic\Music\Application\Query;

final class GetAlbumQuery
{
    public function __construct(
        public readonly string $albumId,
    ) {}
}

final class GetAlbumHandler
{
    public function __construct(
        private readonly AlbumReadModelInterface $readModel,
        private readonly CacheInterface $cache,
    ) {}

    public function handle(GetAlbumQuery $query): ?AlbumDTO
    {
        $cacheKey = "album_{$query->albumId}";
        
        $cached = $this->cache->get($cacheKey);
        if ($cached !== null) {
            return $cached;
        }
        
        $album = $this->readModel->findById($query->albumId);
        
        if ($album !== null) {
            $this->cache->set($cacheKey, $album, ttl: 3600);
        }
        
        return $album;
    }
}
```

### 5.4 CQRS Avantajları

| Avantaj | Açıklama |
|---------|----------|
| Performans | Read model optimize edilmiş |
| Ölçeklenebilirlik | Read/Write ayrı ayrı ölçeklenir |
| Cache | Read tarafı kolayca cache'lenir |
| Security | Write/read ayrı yetki |

## 6. Event Driven Architecture

*Detaylı metadata: [[ADR-086]]*

### 6.1 Event Driven Nedir?

Servisler birbirini doğrudan çağırmaz, event yayınlar:

```
Service A → Event Bus (PSR-14) → Service B, C, D
```

### 6.2 Event Tipleri

| Event Tipi | Kullanım Alanı | Örnek |
|------------|---------------|-------|
| Domain Event | İş mantığı olayları | `AlbumAddedEvent` |
| Integration Event | Servisler arası | `UserRegisteredEvent` |
| Infrastructure Event | Altyapı olayları | `CacheClearedEvent` |

### 6.3 Event Publisher

```php
<?php

declare(strict_types=1);

namespace CoreMusic\Music\Domain\Event;

final class AlbumAddedEvent
{
    public function __construct(
        public readonly string $albumId,
        public readonly string $title,
        public readonly \DateTimeImmutable $occurredAt = new \DateTimeImmutable(),
    ) {}
}

// Publisher
$dispatcher->dispatch(new AlbumAddedEvent(
    albumId: $album->getId(),
    title: $album->getTitle(),
));
```

### 6.4 Event Listener

```php
<?php

declare(strict_types=1);

namespace CoreMusic\AI\Infrastructure\Listener;

final class AlbumAddedListener
{
    public function __construct(
        private readonly RecommendationEngineInterface $engine,
    ) {}

    public function __invoke(AlbumAddedEvent $event): void
    {
        $this->engine->updateRecommendations($event->albumId);
    }
}
```

### 6.5 Event Akışı

```
Music Service: AlbumAddedEvent yayını
  → Event Bus (PSR-14)
    → AI Service: Önerileri güncelle
    → Download Service: Metadata güncelle
    → Analytics Service: İstatistik oluştur
    → Notification Service: Bildirim gönder
```

### 8.2 DTO (Data Transfer Object)

```php
<?php

declare(strict_types=1);

namespace CoreMusic\Music\Application\DTO;

final readonly class AlbumDTO
{
    public function __construct(
        public readonly string $id,
        public readonly string $title,
        public readonly string $artist,
        public readonly int $trackCount,
        public readonly \DateTimeImmutable $releaseDate,
    ) {}

    public static function fromEntity(Album $album): self
    {
        return new self(
            id: $album->getId()->toString(),
            title: $album->getTitle()->toString(),
            artist: $album->getArtist()->getName(),
            trackCount: $album->getTrackCount(),
            releaseDate: $album->getReleaseDate(),
        );
    }

    public function toArray(): array
    {
        return [
            'id' => $this->id,
            'title' => $this->title,
            'artist' => $this->artist,
            'track_count' => $this->trackCount,
            'release_date' => $this->releaseDate->format('Y-m-d'),
        ];
    }
}
```

## 10. SOLID Uygulaması (API İçin)

### 10.1 Single Responsibility (SRP)

| Sınıf | Sorumluluk |
|-------|------------|
| `ApiGateway` | Sadece yönlendirme |
| `AuthMiddleware` | Sadece kimlik doğrulama |
| `RateLimitMiddleware` | Sadece hız sınırlama |
| `AlbumController` | Sadece album HTTP işlemleri |
| `AddAlbumHandler` | Sadece album ekleme mantığı |

### 10.2 Open/Closed (OCP)

Yeni servis eklemek mevcut kodu değiştirmez:

```php
// Yeni servis eklemek için mevcut kod DEĞİŞMEZ
$gateway->registerService('podcast', new PodcastService());
```

### 10.3 Liskov Substitution (LSP)

Tüm handler'lar `HandlerInterface`'i uygular:

```php
interface HandlerInterface
{
    public function handle(object $command): mixed;
}
```

### 10.4 Interface Segregation (ISP)

İnce arayüzler:

```php
interface ReadModelInterface
{
    public function findById(string $id): ?object;
    public function find(array $criteria): array;
}

interface WriteModelInterface
{
    public function save(object $entity): void;
    public function delete(string $id): void;
}
```

### 10.5 Dependency Inversion (DIP)

Controller'lar use case'lere bağımlıdır:

```php
final class AlbumController
{
    public function __construct(
        private readonly GetAlbumHandlerInterface $getHandler,
        private readonly AddAlbumHandlerInterface $addHandler,
    ) {}
}
```

## 12. Kod Örnekleri

### 12.1 API Endpoint

```php
<?php

declare(strict_types=1);

namespace CoreMusic\Music\Controller\Api;

use CoreMusic\Music\Application\Command\AddAlbumCommand;
use CoreMusic\Music\Application\DTO\AlbumDTO;

final class AlbumApiController
{
    public function __construct(
        private readonly AddAlbumHandlerInterface $addHandler,
        private readonly BFFInterface $bff,
    ) {}

    public function store(ServerRequestInterface $request): ResponseInterface
    {
        $command = new AddAlbumCommand(
            title: $request->getParsedBody()['title'],
            artistId: $request->getParsedBody()['artist_id'],
            tracks: $request->getParsedBody()['tracks'] ?? [],
        );

        $album = $this->addHandler->handle($command);
        
        $dto = AlbumDTO::fromEntity($album);
        
        return $this->jsonResponse(
            $this->bff->format($dto->toArray()),
            201
        );
    }
}
```

### 12.2 Repository Interface

```php
<?php

declare(strict_types=1);

namespace CoreMusic\Music\Domain\Repository;

use CoreMusic\Music\Domain\Entity\Album;

interface AlbumRepositoryInterface
{
    public function findById(string $id): ?Album;
    public function save(Album $album): void;
    public function delete(string $id): void;
    public function findByArtist(string $artistId): array;
}
```

### 12.3 PDO Repository

```php
<?php

declare(strict_types=1);

namespace CoreMusic\Music\Infrastructure\Repository;

use CoreMusic\Music\Domain\Repository\AlbumRepositoryInterface;
use CoreMusic\Music\Domain\Entity\Album;

final class PdoAlbumRepository implements AlbumRepositoryInterface
{
    public function __construct(
        private readonly \PDO $pdo,
    ) {}

    public function findById(string $id): ?Album
    {
        $stmt = $this->pdo->prepare(
            'SELECT id, title, artist_id, release_date, created_at 
             FROM albums WHERE id = :id AND is_deleted = 0'
        );
        
        $stmt->execute(['id' => $id]);
        $row = $stmt->fetch(\PDO::FETCH_ASSOC);
        
        if ($row === false) {
            return null;
        }
        
        return Album::fromRow($row);
    }
}
```
