# MJL21193 PNP Güç Transistörü

## Genel Bakış

MJL21193, OnSami tarafından üretilen yüksek güçlü PNP bipolar güç transistörüdür. MJL21194 (NPN) ile tamamlayıcı çift oluşturarak Class AB push-pull çıkış katında negatif half-cycle'ı sürer. Elektriksel ve termal özellikleri MJL21194 ile simetrik olarak eşleşmiştir.

## Tamamlayıcı Çift Eşleştirme Kriterleri

```
Eşleştirme Test Koşulları:
├── hFE: ΔhFE/hFE ≤ %5 @ I_C=4A, V_CE=4V
│   ├── hFE_NPN: 100 (typical)
│   └── hFE_PNP: 100 (typical)
│   └── ΔhFE: ≤ 5 (maksimum)
│
├── V_BE: ΔV_BE ≤ 10mV @ I_C=1A
│   ├── V_BE(NPN): +650mV
│   └── V_BE(PNP): -650mV
│   └── ΔV_BE: ≤ 10mV (magnitüd)
│
└── Termal: Paket eşitliği
    ├── Mounting pressure: 10-15 lbf·in
    └── Thermal compound: eşit dağılım
```

## Push-Pull Simetri Analizi

```
Pozitif half-cycle (Q9=MJL21194 aktif):
├── I_C = 0 → 4A (peak)
├── V_CE = 35V → 1V (saturation)
├── Gain: hFE = 100 @ 4A
└── V_BE = 0.65V (ileri bias)

Negatif half-cycle (Q10=MJL21193 aktif):
├── I_C = 0 → -4A (peak)
├── V_CE = -35V → -1V (saturation)
├── Gain: hFE = 100 @ -4A
└── V_BE = -0.65V (ileri bias)

Simetri hatası: ≤%0.1 THD (eşlenmiş çift ile)
```

## Termal Eşleme

```
Q9 (MJL21194) ───────────┐
                          │ ← Thermal compound (1-2 mil)
Q10 (MJL21193) ──────────┘
                          │
Heatsink (alüminyum) ─────┘
                          │
Fan (opsiyonel) ──────────┘

Termal dirençler (seri):
R_θ(j-c) = 0.41°C/W (her transistör için)
R_θ(c-s) = 0.5°C/W (thermal compound)
R_θ(s-a) = 1.5°C/W (heatsink)
R_θ(j-a) = 0.41 + 0.5 + 1.5 = 2.41°C/W

Sıcaklık farkı @ 100W:
ΔT = P × R_θ(j-a) = 50W × 2.41°C/W = 120.5°C
T_j = 25 + 120.5 = 145.5°C (< 150°C limit) ✓
```

## Güvenlik Sınırları

1. **Polarity**: PNP ters polarma dc voltajına duyarlı
2. **V_EBO**: -7V'dan fazla reverse bias → junction hasarı
3. **Second Breakdown**: SOA sınırlarına riayet
4. **Termal runaway**: hFE termal artışı kontrol edilmeli
5. **Latch-up**: Darlington yapıda parasitic SCR riski
